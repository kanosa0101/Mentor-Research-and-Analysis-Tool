打开浏览器收藏与待办 →

正式申请项目、材料文件路径、邮件草稿与沟通记录仍由本机版管理，不会上传到公开站。浏览器收藏不会自动变成正式申请项目。

第一次使用本机版

下载 v1.10 本机运行包 → · SHA256 校验码

  1. 将运行包解压到独立目录，按包内 README 安装 Python 与依赖。
  2. 启动本机服务，进入“申请导航”。
  3. 先在本页所属浏览器导出收藏备份，再到本机页面导入；确认后即可从目标或收藏建立正式申请。

浏览器记录不会随网址跳转自动搬运；备份文件也不会上传到公开站。

已有本机版：在项目目录运行 python scripts/serve.py，再打开本机页面保存申请、关联材料和设置提醒。
