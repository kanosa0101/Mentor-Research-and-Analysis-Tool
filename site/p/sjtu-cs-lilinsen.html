个人简介 李林森， 西北工业大学电子系博士，上海交通大学电子工程系博士后，美国加州大学洛杉矶分校(UCLA)国家公派访问学者，IEEE会员，NSFC和科技部项目评审人，中国网络空间安全协会会员，教育部学位中心论文评阅人，上海交通大学计算机学院副教授、硕士生导师。与法国科学家J. Louis合作研究RFID，与美国R. Gadh教授及日本shift株式会社合作研究物联网，与何积丰院士、浙江中控合作研究工业互联网。赴法国主持SSIC 2016分会，在澳大利亚ACSCS 2016上做主旨演讲，赴剑桥大学参加ICC’17并宣读论文。主持了ZF预研、国家重点研发计划项目“工业控制系统安全保护技术应用示范” 的课题任务“工控系统综合安全评估认证技术及等保体系研究”(课题编号：2018YFB0803503)，国家自然科学基金联合基金重点项目“基于感知搜索物联网的工业供需链关键技术研究”（ U1509219 ）的课题“物质资源的虚拟感知技术研究”，国家自然科学基金面上项目“面向物联网的超高频无源无线识别系统安全机制研究”（ 61071078 ），上海市科委项目“基于RFID及二维码的危险化学品信息安全和防爆安全技术研究”（16DZ1200702），“基于大数据的慢病管理平台数据安全和隐私保护”（16511102605）等多项科研工作，发表学术论文70多篇，授权国家发明专利5项，开发了RFID读写器和物联网智能监控系统。1项成果入选中国高等学校十大科技进展，1项成果获2021年中国安全生产协会科技进步二等奖。成功申请医疗大数据应用技术国家工程实验室（共建单位）。 研究方向：信息安全，物联网安全，工业互联网安全，硬件系统安全 教育背景 1996/9-2000/6 ，西北工业大学，电子系，博士 1993/9-1996/7 ，西安矿业学院，自动化系，硕士 工作履历 2002/10 至今，上海交通大学，电子信息与电气工程学院，副教授、硕士生导师 2013/2–2014/2 ，美国加州大学洛杉矶分校 (UCLA) ，工程学院机械与航空航天系，国家公派访问学者 2000/6–2002/9 ，上海交通大学，电子信息与电气工程学院电子工程系，博士后 1989/8-1993/7, 电子部第七九四厂，助理工程师 教授课程 （1）物联网安全（本科生课程NIS4349） （2）硬件系统安全（本科生课程NIS3602） （3）无线电安全（研究生课程NIS8016） （4）路由原理及协议（本科生课程IS302） （5）计算机通信网络设计与分析（研究生课程P036501） （6）通信理论与系统（研究生课程X036507） （7）数字集成电路理论与设计（研究生课程X034509） 论文发表 (1) Zewei Pan; Linsen Li ; Tongxin Yuan; Jiarong Yang; Point Cloud Registration via Reconstruction with Local Geometry Information Aggregation, 2025 IEEE International Conference on Acoustics, Speech and Signal Processing (ICASSP 2025, CCF-B), Hyderabad, India, 2025-4-06 至2025-4-11 (会议论文) ( 本人标注: 唯一通讯作者 ) (2) Xubo Yang; Linsen Li ; Yenan Chen ; Neural Network Backdoor Attacks Fully Controlled by Composite Natural Utterance Fragments, 2023 International Conference on Information and Communications Security (ICICS 2023, CCF-C), Tianjin, China, 2023-11-18 至2023-11-20 (会议论文) ( 本人标注: 唯一通讯作者 ) (3) Shuyuan Xu; Linsen Li ; Hangjun Yang; Junhua Tang ; KCC Method: Unknown Intrusion Detection Based on Open Set Recognition, 2021 IEEE 33rd International Conference on Tools with Artificial Intelligence (IEEE ICTAI 2021, CCF-C), Washington, DC, USA, 2021-11-1至2021-11-3 (会议论文) ( 本人标注: 唯一通讯作者 ) （4）Lingxuan Zhang, *Linsen Li,etc. Quantitatively Assessing the Cyber-to-Physical Risk of Industrial Cyber-Physical Systems.
