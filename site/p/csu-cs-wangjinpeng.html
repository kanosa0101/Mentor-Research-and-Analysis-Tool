个人简介（官网原文）

王金鹏，博士，中南大学计算机学院特聘教授，博士生导师， 国家高层次青年人才。 研究兴趣集中在人工智能中的多模态大模型(1000GPU和100亿样本级别)，以数据为中心的AI以及VLA。在中山大学(SYSU)获得了学士和硕士学位。在 新加坡国立大学(NUS)三年完成了博士学位 。 Github Star超过 5000 ，有常年训练 1000+ 左右GPU经验。 第一作者/共同一作发表CCF-A类会议/期刊 10余 篇, 详细见 https://scholar.google.com/citations?user=UtaAVacAAAAJ&hl=zh-CN 。个人主页： http://fingerrec.github.io 。 实验室主页： https://csu-jpg.github.io 。 具体方向： 大模型如GPTV, Gemini，Deepseek等以及GUI-Agent如Open-claw模型等正在对生产力进行全面革新， 全面拥抱AI 已经成为不可阻挡的趋势。而且日新月异，对很多传统行业/研究方向提出了巨大挑战，但也是最好的机遇。我们课题组主要集中在前沿多模态大模型方面研究，主要集中在： 1.以视觉为中心的多模态大模型：大规模预训练/后训练; 对主流多模态大模型如Qwen, Intern-VL中一些缺乏能力的Post Training； 2. 具身智能, Vision-Language Action Model。Multi-agent systems.
