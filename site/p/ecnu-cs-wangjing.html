个人简介（官网原文）

华东师范大学晨晖学者（助理教授）。上海交通大学博士和博士后，入选上海市超级博士后激励计划，作为核心成员参与国家重点研发、国家重点研发青年科学家、科技部2030、国自然区域联合重点等多项国家级项目，在SC、ISCA、HPCA、VLDB、IPDPS、ICCD、APPT等会议，以及TC、TPDS、TACO、JPDC、CSUR等期刊上发表论文，拥有多项美国和国内专利授权，研究成果落地阿里、字节、蚂蚁等企业平台。研究内容主要面向新兴应用设计软硬件协同的高效内存系统，具体包括：分离式内存池、图计算、GPU加速、FPGA编译、资源调度等。任职CCF体系结构专委、分布式专委、存储专委执行委员，担任TPDS、TC、TSUSC等审稿人。其他内容详见个人主页，欢迎联系交流。 社会兼职  中国计算机学会体系结构专委执行委员（ 2024.7- 今）  中国计算机学会分布式系统专委执行委员（ 2024.7- 今）  中国计算机学会信息存储技术专委执行委员（ 2024.11- 今） 研究方向 我的主要研究方向为计算机体系结构，面向智能体、大模型、图计算等新兴应用场景，研究异构架构设计、内存存储系统优化、专用加速器编译优化、资源动态调度等，支撑先进计算的底层效能提升。 Research Interests: My primary research area is Memory System for Emerging Application (short as MemSea ) . I work hard to build wisdom, high-performance, and sustainable memory subsystems for next-generation computer architectures on the basis of heterogeneous computing, memory, storage, and network devices. Our design can serve a variety of big-data applications, including multi-modality AI training, AI content generation (AIGC), large language model (LLM), retrieval-augmented generation (RAG), graph processing, metaverse, cloud gaming, scientific computing, and others. We have made some progress on far memory system design, graph processing acceleration,  resource scheduling in the cloud, task rearrangement at the edge, etc. Now, we are mainly working on the following fields: System Design for LLM and Agent workload Smart Management of flat disaggregated memory Exploration of out-of-xPU memory and Storage architecture Compilation optimization of FPGA Architecture (If you are interested in these research areas, please feel free to contact me now !
