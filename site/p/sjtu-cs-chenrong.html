个人简介（官网原文）

个人简介 陈榕，上海交通大学教授、ACM杰出会员。主要研究领域为操作系统、分布式系统等基础系统软件。在操作系统领域CCF A类会议和期刊发表论文40余篇（包括16篇OSDI/SOSP、15篇EuroSys/ATC论文），研究成果获得EuroSys（2次）、APSys和ICPP等国际会议最佳论文奖。担任本领域最重要期刊《ACM Transactions on Computer Systems》编委，受邀二十余次担任OSDI、SOSP等系统领域会议程序委员会委员。先后主持多项国家重点研发计划、自然科学基金等项目/课题，以及十余项企业合作项目。曾获2023年国家技术发明二等奖、2019年上海市技术发明一等奖、2018年教育部技术发明一等奖，以及2020年华为奥林帕斯先锋奖等。 教授课程 Introduction to Computer Systems: 2025–2012 Operating Systems: 2018, 2017, 2015, 2013 Distributed Systems: 2016, 2015, 2014 Advanced Distributed Systems: 2025–2017, 2013, 2012 Computer System Design & Implementation: 2019, 2018, 2017 论文发表 [ EuroSys ] KunServe: Parameter-centric Memory Management for Efficient Memory Throttling Handling in LLM Serving .
