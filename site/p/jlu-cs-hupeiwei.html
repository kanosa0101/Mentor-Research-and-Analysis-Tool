个人简介（官网原文）

胡佩威 职称：助理教授、博士生导师 毕业院校：中国科学院大学 Email ： peiwei@jlu.edu.cn 个人简介 胡佩威，吉林大学计算机科学与技术学院助理教授，博士生导师。 2025 年获得中国科学院大学工学博士学位，在学期间获得所长特别奖（全所 6 人）、国家奖学金。主要研究方向为软件与系统安全、大语言模型在网络安全中的应用。以第一作者与合作作者身份在网络安全四大顶会 CCS 、 USENIX Security 、 NDSS 、 S&P 及其它高水平会议发表论文多篇，研究成果在著名开源程序中发现超过 500 个安全缺陷，并为开源社区 OpenSSL 、 Rizin 、 Linux Kernel 贡献大量缺陷修复与性能优化代码。 本课题组致力于发现真实世界中存在的各种安全问题，构建有效的缺陷发现工具；并积极探索新兴软硬件系统中可能存在的缺陷。每年招收博士研究生 1 名，硕士研究生多名，在读研究生在学校奖学金基础上可获额外科研津贴，欢迎对科研充满热情且具有内在驱动力的同学投递简历（邮箱： peiwei@jlu.edu.cn ，个人主页获取最新信息： hupeiwei.com ）。 工作经历 2025.08- 至今 吉林大学 计算机科学与技术学院 助理教授、博士生导师 教育经历 (1) 2020-09 至 2025-06, 中国科学院大学 , 信息工程研究所 , 工学博士 (2) 2016-09 至 2020-06, 吉林大学 , 计算机科学与技术学院 , 理学学士 论文发表 (1) DeGPT: Optimizing Decompiler Output with LLM (NDSS 2024, CCF-A, 网安顶会，独立第一作者 ) (2) AURC: Detecting Errors in Program Code and Documentation (USENIX Security 2023, CCF-A, 网安顶会，独立第一作者 ) (3) TypeForge: Synthesizing and Selecting Best-Fit Composite Data Types for Stripped Binaries (IEEE S&P 2025, CCF-A, 网安顶会，合作作者 ) (4) Optimizing Decompiler Output by Eliminating Redundant Data Flow in Self-Recursive Inlining (ICSME 2024, CCF-B, 合作作者 ) (5) Boosting neural networks to decompile optimized binaries (ACSAC 2022, CCF-B, 合作作者 ) (6) The inconsistency of documentation: a study of online C standard library documents (Cybersecurity 2022, CCF-C, 合作作者 ) (7) Neutron: an attention-based neural decompiler (Cybersecurity 2021, CCF-C, 合作作者 ) (8) Rtfm! automatic assumption discovery and verification derivation from library document for api misuse detection (CCS 2020, CCF-A, 网安顶会， 合作作者 )
