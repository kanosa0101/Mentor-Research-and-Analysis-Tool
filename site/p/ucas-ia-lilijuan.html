李丽娟 / 职　　称: 副研究员 邮　　编: 100190 电子邮件: lijuan.li@ia.ac.cn 部门/实验室: 复杂系统认知与决策实验室 通讯地址: 北京市海淀区中关村东路95号 个人简历 李丽娟，中国科学院自动化所副研究员，毕业于清华大学微电子学研究所，获工学博士学位。研究领域为智能博弈学习和信息安全。中国科学院人工智能创新研究院首批“2035创新团队”成员，作为核心骨干参与多项国家级重点项目、中国科学院战略性先导研究项目及面上项目。在大规模不完美信息博弈、多智能体学习、智能身份识别等方面具有丰富的研究和应用经验。在国内外顶级期刊和会议发表多篇一作论文，研发的大数模乘算法研究及SM2/3/4高性能密码算法芯片曾获得党政机要密码科学技术进步二等奖（省部级）。近年来围绕博弈智能决策问题，研发了多项针对不同复杂博弈问题的决策AI。 研究方向 智能博弈学习 承担科研项目情况 1. 航迹规划算法，横向； 2. 多智能体智能规划决策算法，横向； 3. 智能学习框架与算法研究，横向； 代表论著 1. Inducing Stackelberg Equilibrium through Spatio-Temporal Sequential Decision-Making in Multi-Agent Reinforcement Learning, IJCAI 2023; 2. Multi-Agent Hyper-Attention Policy Optimization, ICONIP 2022; 3. Sample Efficient Reinforcement Learning Using Graph-based Memory Reconstruction, TAI 2023; 4.  Controlling Large Language Model-based Agents for Large-Scale Decision-Making: An Actor-Critic Approach, LLMAgents @ ICLR 2024. 5. Learning to Play Hard Exploration Games Using Graph-guided Self-navigation, IJCNN 2021. 获奖及荣誉 1. 大数模乘算法研究及SM2/3/4高性能密码算法芯片，党政机要密码科学技术进步奖 二等奖（省部级），2017年； 2. 2021全国空中智能博弈大赛，全国第三名。
