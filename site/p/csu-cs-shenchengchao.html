个人简介（官网原文）

沈成超，现为中南大学计算机学院特聘副教授、硕士生导师（ 个人主页 ）， 主要从事计算机视觉研究，涉及视觉/多模态大模型、LLM Reasoning、无监督学习、 模型推理加速等，发表包括CVPR、ICCV、ECCV、AAAI、NeurIPS、IJCAI等20 余 篇国际计算机视觉/人工智能论文，并在 Google Scholar 上被引用1400余次，担任NeurIPS、ICLR等国际顶会领域主席（ Area Chair） ，NeurIPS Top Reviewer， 主持国家自然科学基金、湖南省自然科学基金、长沙市自然科学基金多项，担任 湖南省人工智能学会委员、青工委副秘书长 。 【 讲授课程 】①计算机组成原理与汇编（必修课，64课时，秋冬学期，本科生）②计算机视觉前沿技术（选修课，32课时，春夏学期，本科生） 【 招生信息 】课题组长期招收研究生，欢迎对 热爱研究 、 技术 的学生加入课题组，群发邮件不回。 【 联系方式 】scc.cs@csu.edu.cn 【 相关链接 】[ Homepage ] [ Google Scholar ] [ DBLP ] [ Github ] [ Zhihu ] 【 开源工程 】 Word Agent ，基于AI智能体的写作辅助系统，WPS、MS Word插件 代表论文 --------------------------- Large Multimodal Models --------------------------- • Hao Tang, Chengchao Shen* . Learning Compact Vision Tokens for Efficient Large Multimodal Models. Arxiv, 2025.
