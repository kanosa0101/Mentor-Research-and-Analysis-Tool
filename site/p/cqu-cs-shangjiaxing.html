个人简介（官网原文）

个人简介 Personal Profile 尚家兴，教授/博士，博士生导师，欧盟“玛丽·居里学者”，中国计算机学会（CCF）会员，IEEE/ACM会员，CCF数据库/协同计算/普适计算专委会员，中国现场统计研究会大数据统计分会常务理事，现任职于重庆大学计算机学院。主要研究方向为民航大数据分析、时序数据挖掘、可解释人工智能、社交网络挖掘等。2010年于清华大学自动化系获学士学位，同年保送至清华大学直接攻读博士研究生，并于2016年1月获清华大学自动化系博士学位。2014年9月-2015年1月于香港城市大学进行学术交流访问；2016年2月至2018年8月在重庆大学计算机学院任职讲师，2018年9月至2023年8月任职副教授，2023年9月至今在重庆大学计算机学院任职教授。截止到目前，共发表论文100余篇，其中SCI等期刊论文50余篇，CCF高水平国际会议论文30余篇，包括TKDE, TITS, TNNLS, TETC, PR, DASFAA等CCF推荐高水平国际期刊和会议论文；申请专利30余项，授权20余项。主持和参与国家重点研发计划课题、国家自然基金青年基金、民航联合基金重点项目、重庆市自然基金、横向研究课题等项目20余项，与中国民航科学技术研究院、中国民用航空飞行学院、中国科学院自动化研究所等单位建立了长期合作关系。担任TKDE、TNSE、TPAMI、TSMCA、TITS、 TCSS、 ACM TWEB、计算机学报等期刊和国际会议审稿人。担任WASA'17会议Session Chair，ICC'19/ICC'20 MWN Symposium TPC Member，DSONAM'20 workshop chair，HHME 2020 Session Chair。Github个人主页： https://jxshang.github.io/ 课题组最近更新： [ 2026/05 ]: 课题组硕士生 徐蓉 、 管梦雅 虚假新闻检测论文被 TKDE （ CCF-A ）接收！ [ 2026/03 ]: 课题组硕士生周玉昆信息传播预测论文被 KSEM （ CCF-C ）会议接收！ [ 2026/03 ]: 课题组硕士生管梦雅、徐蓉虚假新闻检测论文被 TKDE （ CCF-A ）接收！ [ 2025/12 ] : 课题组硕士生李诚祥QAR研究论文被 IEEE Sensors Journal （ JCR一区 ）接收！ [2025/11] : 课题组硕士生黄友霖QAR研究论文被智能交通领域顶刊 TITS （ CCF-B ）接收！ [2025/10] : 课题组硕士生王鯨清论文被 CCF-B 类会议 WSDM （录稿率100/613=16.3% ）接收！ [2025/07] : 课题组硕士生贾雪琪论文被 CCF-A 类期刊 TKDE （中科院 一区Top ）接收！ [2025/06] : 课题组硕士生熊浩宇论文被 CCF-C 类期刊 Knowledge-Based Systems （中科院 一区Top ）接收！ [2025/05] : 课题组博士生蔡炯飚论文被 CCF-B 类期刊（中科院 二区Top ，智能交通领域顶刊） TITS 接收！ [2025/04] : 课题组硕士生张锐祥、李筱荃论文被SCI 期刊 （中科院 一区Top ） EAAI 接收！ [2025/03] : 课题组硕士生钟林泱、张玉璇论文被 CCF-C 类期刊 （中科院 一区Top ） Data Science and Engineering 接收！ [2025/02] : 课题组硕士生陈露论文被 CCF-A 类中文期刊《 自动化学报 》 （中国科技期刊卓越行动计划二期 领军期刊 ）接收！ 代表性论文（*为通讯作者） 行业大数据分析方向（主要面向民航）： [1] Youlin Huang, Jiaxing Shang *, Xu Li, Linjiang Zheng, Chengxiang Li, Fan Li, Xinbin Zhao, Huabo Sun, Riquan Zhang. MultiSafe: Multiple Flight Safety Events Prediction Based on Interpretable Deep Multi-Task Learning, IEEE Transactions on Intelligent Transportation Systems (TITS) , 2025, 27(2): 2088-2100.
