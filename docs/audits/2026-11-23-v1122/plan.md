# v1.12.2 优化与验收计划

目标继续围绕现有在线产品的使用体验与真实信息覆盖。v1.12.1 已发布，生产源码和最终文档提交分别为 `3ae11b4aac68307d75ebf9017a912c14123f87e1`、`6d212b4b278f8e3637816f53d0816b03899707b7`。本轮不新增业务模块，子任务独立核验后统一交付。

1. **首次浏览与学校切换**。学校要求页即使未选学校，也内联约1.09 MB政策、证据及材料动作，公网gzip约228 KB；400 kbps、300 ms RTT及4倍CPU限速的手机测试中首次就绪中位数约7.8秒。将未选学校的目录与所选学校的完整内容分开加载，保留每条政策证据及材料语义。验证未选校不请求政策正文、深链接只读对应学校、快切学校不串结果、失败/超时可重试、版本更新不混用旧分片，并比较相同网络条件下的传输与就绪时间。
2. **手机找导师首屏**。390像素宽度首次打开时，第一张卡片从页面约727像素处才开始。手机默认收起完整筛选表单，保留明显的展开入口和未应用修改提示；桌面筛选栏照常展开。验证320/390宽度首屏可见完整第一张卡片，姓名/关键词/学校/资格均可操作，收起不自动应用草稿，换批仍采用已应用条件，提交后显示结果，错误保留输入，桌面与手机切换不丢值。
3. **导师来源与字段补齐**。Sol子代理分别负责浙江大学计算机、华中科技大学网络安全与人工智能及自动化。以当时生产原始字节快照为基准，核验现行官方名录、本人页和具名附件，修正专属适配器，保留非空冲突与身份歧义。每个批准字段提供来源、原文SHA和观测时间，按真实生产基线统计增量；用现有维护入口重新抓取或回放验证可持续补齐。
4. **集成与上线**。公开资料按逐文件生产SHA比较，拒绝覆盖较新数据；保留账号、申请、材料及其他服务。完整回归、独立资料审查、Windows/Ubuntu构建与CI、真实HTTPS申请流程及手机/桌面布局均通过后发布。部署后逐项核对新增信息在公开目录/接口中可见，并恢复维护服务、保存Git与服务器版本绑定。

本轮来源失败、同名歧义、官方未公开等仍按实际原因记录；资料存在来源不等于当前有招生名额。软件发布也不替代当期院校活动和招生政策的独立核验。
