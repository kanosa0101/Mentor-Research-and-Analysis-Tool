# v1.12.6 导师资料持续补齐计划

2026-11-23。以已完成线上验收的 v1.12.5（`0871636a7137722f10587e0aaa36e59ad9c8810b`）为基线。沿用纯在线版和既有页面，不增加学生业务模块。

1. **确认缺口与来源。** 两名 Sol 子代理分别核对中国人民大学信息学院、高瓴人工智能学院的当前名册、本人页面和生产档案；第三名子代理继续只读核查当前院校活动。保留官方原字节、时间与逐条差异。未公开的资格、冲突联系方式和身份不清的迁移不自动补入。
2. **修复持续采集。** 仅修复两个院系的现有适配器及必要配置，用真实页面回放现有字段补齐、资料复核与失效恢复流程。检验本人研究栏目边界、个人来源归属、人工字段保护和重复运行；人工批量修改不代替持续更新能力。
3. **验收用户可用性。** 核对新方向能出现在找导师、详情和对比中并支持既有关键词筛选；学校、申请与联系人上下文保持一致。检查手机和桌面排版，只有复现的问题才修改界面。新增官方活动必须独立满足主办层级、对象、届别和时效门禁。
4. **发布与复验。** 通过针对性检查和完整回归后，按生产前值校验合入核验数据；保留私人记录和其他院系更新。部署、GitHub 与版本标记绑定，复验公网流程及定时维护，分别报告实际补齐数量、无法核验的缺口和当前活动增量。

本轮不调用付费 AI 接口；上轮已确认余额不足，规则可以直接核实的官方结构化字段继续由现有采集流程处理。

## 首轮复现

- 真实公网 1440、390、320 像素视口：推荐为四张等高卡，页面没有横向溢出或脚本错误。信息学院卡片因方向缺失退回履历摘要；补齐方向后复测这条浏览路径。
- 导师详情的正文仍使用旧模板 13.5px 字号，且“旧套磁记录”横在联系方式与个人简介之间。本轮仅让详情正文服从共享 15px 正文规范，把旧记录移到资料及来源之后；保留原有访问和操作。
- 信息学院名录将姓名、方向和课程包在同一个链接里，现有恢复器把整张卡当姓名。共享恢复器增加该官方目录的明确姓名单元识别，保留原来的“姓名与独立身份依据一致”门禁。
