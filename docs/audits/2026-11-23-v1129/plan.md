# v1.12.9：来源可读性与导师资料补全

本轮沿用纯在线版和每次四位推荐，不新增学生业务模块。导师事实由 Sol 子代理批量核对，主代理负责产品、共享规则、集成与部署。没有本人官方证据的字段不猜测、不用当日解析时间冒充来源日期。

## 四阶段与验收

1. **复现用户问题**：以线上真实导师来源记录为基准，记录 320、390 像素下字段、完整日期与出处不能同时阅读的问题；确认桌面表格和申请上下文的既有行为。
2. **收敛展示**：窄屏按字段阅读来源，保留实际内容、来源类型、核对状态与原文；缺失日期或出处明确标识。验收长研究方向、长 URL、人工来源、键盘操作、桌面与手机，无隐藏值或横向阅读要求。
3. **有证据地补全**：南京大学、中国科大按各自官方页面批量核验方向与联系方式，修复方向混入履历、实验室误作个人主页及非人物名单项。按字段保护人工和其他来源的内容，正常采集入口验证可持续性；独立审校后才允许导入。非人物记录仅在来源、引用影响及防再入库均核验后处理。
4. **验证与交付**：导入前重新取得生产快照并比较原值，保留生产新增数据；运行相关回归、全量检查和 Linux CI，部署后实际验证资料、搜索、四位刷新与申请流程。记录精确源码、发布版本、备份、保护文件和部署结果；实际用户验收仍由用户进行。

## 范围与约束

- 界面修改只针对导师详情的来源记录，不调整已通过验收的四位推荐规则。
- 共享采集规则只有在正常入口复现问题后才作最小修复，优先单位 opt-in。
- 原始 HTTP 响应、请求/最终 URL、UTC、摘要和审批清单保存在对应 `cache/v1129` 证据目录；不把试点成功说成全面覆盖。
- 不调用尚未恢复额度的收费 AI 服务。维护定时器的自然轮转与孤立试点结果分别记录。
- 账号、上传材料、沟通记录和服务器原有 443 服务不属于修改范围。
