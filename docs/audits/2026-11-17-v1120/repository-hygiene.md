CI 使用 Python 3.12、Node 24 和 Chromium。安装开发依赖后运行 `pip check`，再安装 Chromium 及 Linux 所需系统库，随后构建站点，执行 Python 和 Node 测试以及预检。检出的 GitHub 凭证不写入仓库配置，工作流只授予内容读取权限。

生产依赖引用根依赖并增加维护推送组件，开发依赖再引用生产依赖。PDF、Office、图片及二维码解析与网站构建依赖共用一份声明。以前的本机 ZIP 工具用于历史版本，当前在线版本继续在入口处拒绝生成。临时环境配置、本机缓存和第三方研究原文目录有明确的 Git 排除规则。
