# v1.12.0 找导师页面回归

以已部署的 v1.11.9 为基线，用 Playwright 匿名查看找导师、学校要求及我的申请入口。巡检宽度为 1440、390、320 CSS px。下面两项修正在找导师页面实现。

| 复现 | 修正及验收 |
| --- | --- |
| 从带有学校、院系、入学年度、学位、渠道和招生范围的找导师页面点击顶部“学校要求”。原版进入未选学校、院系或年度的默认画面。点击顶部“我的申请”也会丢失这些参数。 | 顶部“学校要求”沿用候选页面的已应用学校和院系，并携带显式申请范围。顶部“我的申请”与页内链接指向同一申请目标，选导师或清除导师院系筛选后继续保留既定申请目标。已有项目链接沿用项目 ID。匿名登录回跳保留对应参数。 |
| 桌面视口向下找筛选按钮并提交姓名，筛选结果更新后候选摘要可能留在视口上方。桌面及手机在同一位置提交超过 100 字的姓名，错误提示也可能位于当前视口之外。 | 筛选成功时将已偏离视口的桌面候选摘要带回可见区，移动端维持提交后定位。显式提交失败时定位并聚焦错误提示，保留上一次结果。首页初始化、分页以及详情返回仍按原有流程恢复。 |

定向浏览器用例验证了提交成功、空结果、超长姓名、第一页和第二页、点击导师详情后返回、学校级目标、单独项目 ID、清除院系筛选及匿名登录回跳。导师资格筛选不会被带入申请学位。

以浙江大学计算机学院、2028 年硕士推免普通招生为输入，公网原版顶栏两个链接均丢失上下文。用本地编译的找导师页面重复操作后，学校要求能正常选中六项输入，匿名访问我的申请时登录页的 `next` 也保留这六项。

| --- | ---: | ---: | ---: | ---: |

逐项结果和截图保存在 `cache/v1120/ux-public`，本轮未登录、创建申请或修改生产。
