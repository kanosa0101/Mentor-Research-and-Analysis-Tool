## 来源与自动维护

[西电学院名录](https://cs.xidian.edu.cn/szdw/dsjs.htm)保留同名多链接的身份约束。本人页须通过学校标题、可见姓名和个人目录自链核对，研究栏目不能越过相邻标题。旧 HTTP 登记只在明确允许的 `web.xidian.edu.cn` 范围内按真实跳转采集，拒绝 HTTPS 降级。李瑞的多次 HTTP／HTTPS 往返未作为本批发布依据。

李宇楠旧短入口会发生不安全跳转。学院名录的具名链接指向同一大小写个人目录下的[完整 HTTPS 首页](https://faculty.xidian.edu.cn/LIYUNAN/zh_CN/index.htm)。限定同主机、同目录、无额外参数、中文首页和本人自链后，现有质量队列能恢复 `detail_url` 与 `profile_url` 并补充方向。人工或已核验的旧 URL、明确邮箱冲突均拒绝自动迁移。真实原件回放中，同钟重跑无请求；到期复查只读新地址，问题未重开、字段未重复变化。

[川大教师平台名录](https://faculty.scu.edu.cn/xyjs.jsp?id=1035&lang=zh_CN&PAGENUM=1&totalpage=21&st=0&urltype=tsites.CollegeTeacherList&wbtreeid=1012)按 21 页核对 166 个精确个人路径。两位李辉分别绑定各自路径和 UID，不合并同名人员。方向条目只来自唯一明确栏目及相同个人路径下的方向链接。加密邮箱控件不触发解析器的额外隐式网络请求，学院页脚或其他人员联系方式不入库。

两校保留人工值、已核验值和异源证据。普通采集不绕过联系字段的归属检查；新邮箱和独立主页仍由受管字段流程处理。来源日期来自实际抓取，不把字段更新解释为当前有招生名额。

## 维护回放的实际范围

西电普通维护、质量与 CLI 路径处理 88 条方向变化，另由独立恢复案例处理李宇楠一条。字段队列处理 86 条原缺口方向和张涛邮箱，两个原本可用但带导航前缀的字段不属于缺口队列。鲍亮及彭延国已有邮箱的到期同值核验通过；保留原值不冒充新增量。各路径的部分空页或来源问题仍留置，不将全量尝试数写成成功数。

川大四个维护入口均可补齐相同的 31 个空字段；8 条历史标题污染经过本次独立审定后清理，后续可按同值再次核验。46 个现有方向支持同源同值复查。65 个空方向未找到明确内容、13 个旧模板噪音和 3 个其他非空差异保留具体依据，未自动清空。15 份缺邮箱档案未找到可据以发布的本人明文地址。

目前川大官网已有方向发生真实内容变化时，规则会保留旧字段与旧来源日期，不会稳定自动建立独立变更核验任务；现有混合内容规则未识别的旧噪音也可能没有进入队列。这是下一轮维护工作的明确缺口。独立个人或课题组主页属于可选补充，不把缺少第二个主页地址当成缺少官方资料入口。
