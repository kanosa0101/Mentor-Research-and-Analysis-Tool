# v1.12.5 通知页优化计划

2026-11-23。v1.12.4 公网的手机通知页需要滚动才能看到首条标题。按 2028 届筛选后切到通用政策，沿用的届别条件会挡住已有政策。候选版尚未部署。现网耗时和候选版验收结果见[通知页候选验证](candidate-notices.md)。

- **先看到通知。** 常显学校与院系、本科毕业届别及标题搜索。周期、申请渠道、研究生入学年和活动年放入补充筛选，折叠时显示已选条件。届别规则与官方来源按需展开，结果数和首条官方标题在 390×844 与 1440×900 的首屏可见。
- **从推免通知进入通用政策。** 仅沿用明确的研究生入学年，清除本科毕业届别、活动年与“入学年待核验”筛选，并提示实际变更。学校范围、官方正文与栏目链接、刷新分享以及返回学校要求时的原申请目标继续可用。
- **缩短首屏资源链。** 正常构建使用已有内联入口加载样式和页面脚本。验收检查 387 条真实通知正常筛选、标题和来源安全渲染及原有空态与来源告警。部署后用相同尺寸、目标页和浏览器口径复测首次打开与站内切换，记录首字节、筛选就绪时间、请求数和压缩体积。
