## 通用政策跳转

- **入学年未指定。** 在公网选 2028 届及推免，显示 1 条西电推荐资格通知。切到“查看同年通用政策”后仍带毕业届别，结果为 0。手动清除毕业届别后得到 19 条通用政策。
- **入学年显式选为待核验。** 候选修复的中间版本清除了毕业届别与活动年，保留 `notice_admission_year=unknown`。用真实快照回放，跳转仍从 1 条变为 0。手动清除此筛选后得到 19 条通用政策。

最终候选版将入口统一为“查看通用政策”。以上两条路径均从 1 条推免通知切换至 19 条通用政策，研究生入学年保持未指定。独立测试也验证了显式选中的 2027 入学年会保留，页面会提示已清除的条件。通知、日期归类和跨页衔接合跑通过 49 项测试及 26 项子测试。[浏览器专项](../../../tests/test_notices_compact_v1125.py)

## 首开资源与等待时间

Windows Chromium 直连生产 HTTPS。在 390 和 1440 像素下各运行两轮，覆盖直接打开默认通知、直接打开西电深链及从学校要求实际点击通知，共 12 次。首次打开首字节为 1.21–1.44 秒，筛选就绪为 2.85–3.26 秒。站内切换复用 HTTPS 连接，首字节为 0.327–0.347 秒，筛选就绪为 1.30–1.39 秒。

另以 `curl` 分别从公网和服务器回环进行 4 次 HTTPS GET。服务器回环在握手完成后 0.59–0.87 毫秒返回首字节。公网同阶段为 114–127 毫秒，公网 TLS 握手三次为 139–194 毫秒，另一次约 1299 毫秒。浏览器数据同时显示旧版筛选需要等待独立样式和脚本，连接阶段和资源加载均影响就绪时间。

正常构建的候选版将独立 CSS/JavaScript 资源请求从 8 个减到 0 个。旧版 HTML 的 gzip 体积为 86,992 字节，候选本地按同一压缩级别回放为 105,156 字节。账号状态 API 仍异步读取，现有 HTML 重验证与 gzip 行为沿用。实际公网耗时将在部署后按同一口径复测。

原始测量、两次问题复现和真实快照回放记录在本地 `cache/v1125/notice-qa/`，主要回执为 `browser-observation.json`、`curl-observation.json`、`general-policy-dead-end.json`、`explicit-unknown-admission-dead-end.json` 和 `compact-real-replay.json`。
