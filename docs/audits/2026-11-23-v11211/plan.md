# v1.12.11 收尾计划

本版结束当前优化轮次，不再继续扩展学校或学生端功能。基线是 v1.12.10，最终提交 `893801fc3e146dec61ee7eed33c28c43f7b62627`。保留已上线的每批四位推荐、账号与申请流程、详情阅读顺序及西电和川大资料更新。

## 一、核对现状

补完基线版本主分支和标签 CI、生产版本、保护目录、原有 443 服务及维护定时器的最终复验。未完成独立核验的武大数据和东大来源发现保存为草稿，不计作本版发布内容。

## 二、修复维护断点

川大本人官网研究方向与已登记的有效内容不同时，复用现有抓取响应和原件，进入既有导师质量队列。保留登记值和逐字段日期，不自动发布候选。只有本人、精确登记地址、无跳转的成功响应、栏目和原件哈希一致时记录差异。人工来源、已核验来源、异源内容、空栏目或取证失败不产生推断。

同一候选去重，保留首次待处理时间。人工关闭后的相同候选保持关闭，即使中间官网恢复过旧值；不同的新候选可以重开。未经人工决定的差异在官网恢复旧值时自动结束，再次变化可重新报告。已有 CLI 保存问题清单时保留这类最新人工记录。待审项使用既有告警，不占网络修复预算。

## 三、验收

先用真实原件和受控旧值复现问题，清楚区分测试输入与历史事实；独立复核状态、身份、原件、并发和人工决定。运行完整回归、构建和结构检查。部署后使用生产源码、真实官方请求和隔离目录验证既有维护入口，核对真实差异进入队列及未覆盖登记方向。重新验证四位推荐、登录、建立申请、材料、沟通和跨设备读取。

## 四、上线并结束本轮

只安装本版审定的代码和文档，以生产当前公开数据构建页面，保留账号、材料、审核状态和现有证据。部署前备份并保留失败恢复路径，完成后恢复维护任务。GitHub main、注释标签、线上源码标记和最终 CI 一致后交付，不再自动开启下一轮扩展。
