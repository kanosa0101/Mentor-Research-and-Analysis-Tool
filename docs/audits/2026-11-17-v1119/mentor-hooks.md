## 运行与交付

浙大接入站点级 `parse_contact`。任务从学院招生信息栏目选择年份最新且唯一的导师公告，再选择该公告当前发布的正式附件。附件需与公告年份一致，各页表头还需与附件年月一致。公告和附件均可换址，出处仍记录实际读取的原文。变更已发布邮箱时，用已留存的旧附件校验旧姓名、原邮箱和所室机构，并要求新名册行的所室一致。身份依据缺失或机构变化时保留已核验邮箱和出处。附件处理仅启用在配置的官方主机和院系发布附件路径。华科两个配置共用实名个人页钩子，每次从本人页跟随当时明确链接的完整个人简介。其门户当前登记地址为 HTTP，定时请求针对精确主机开启 HTTP 许可，跨机构边界和来源请求预算仍由维护任务校验。

以 648 条登记跑过正常 `mentor_fields.run`，用 143 份现场及已留存官网原文回放，回放未发出 HTTP 请求。部署前的独立 SHA 核验覆盖 46 份导师 YAML 和 3 份原文证据。46 份 YAML 的其他字段及来源保持原状。清除隔离台账后重新处理 648 条，46 个交付邮箱的值和来源保持一致，2 个模拟人工字段得到保留，零项新增。
