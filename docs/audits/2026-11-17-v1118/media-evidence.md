# 官方报名入口与图片证据边界

本轮只修复现有自动核验阻断，不新增学生功能。图片处理不使用生成式AI，不把网页里的指令当作系统指令。

- 官方文字已明确给出完整HTTPS报名URL时，纯文本入口与超链接同样取证。多个不明确入口仍阻断；问卷仅接受明确的腾讯问卷`wj.qq.com/s2/…`路径，逐跳检查、有限GET、有限字节，不注册、不提交。
- HTTP 200只说明公开入口可访问，不证明表单后台仍收件或所有隐藏必填项均已核验。当前报名窗口仍来自正式公告。
- 二维码必须唯一解码，与相邻官方文字中的URL逐字一致，二维码外不能另有海报文字。二维码图片字节进入组合版本，图片变化不能沿用旧AI结论。
- “精彩瞬间”标题本身不是忽略图片的理由。末尾历史图库须有已实际目视核验的同一图片SHA、同一公告URL和用途记录。没有记录或图片变化时继续待核验。
- DOCX里的每张媒体图片都要核对；目前仅允许本次目视确认的机构标志按字节复用。不能按`image1.png`名称、宽高或“logo”文字猜测图片没有条件。

最初两项视觉核验为人工确认，之后仅相同字节可自动复用。不得把这描述为系统能自动读懂所有图片或首次遇到任意新图即可发布。记录位于`sites/evidence_media.yaml`；原官方正文和DOCX、媒体字节在隔离证据目录保留。

真实完整collect取得2189字、2份DOCX，并保留页面发布日期2026-11-02。首次和发布前取证均重新获取官方证据；活动年2027不能推断毕业届别2028。

二维码解码使用ZXing-C++ Python绑定3.1.1和Pillow。Windows及生产Linux均安装3.1.1；生产`pip check`通过。开发曾尝试2.3.0，因Python3.14无现成wheel而中止编译，最终只使用3.1.1。来源：[ZXing-C++官方Python说明](https://github.com/zxing-cpp/zxing-cpp/blob/master/wrappers/python/README.md)。
