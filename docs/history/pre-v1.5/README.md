# 导师库 · 申请助手

**v1.4.0 本机版与公开信息站 · 2026-11-15**。面向CS学生，从找导师、核对招生政策，到整理申请项目、材料、联系历史和提醒。本版整理招生通知届别和阶段，新增统考政策复核及PDF核验发布；保留方向联系人检索、轮转刷新和自愿订阅通知。v1.0 运行包及验收记录保留为历史交付。

## 启动

需要Python 3.12+，本次验证Windows、Python 3.14。解压运行包到独立目录，在该目录执行：

```powershell
python -m pip install -r requirements.txt
python scripts\serve.py
```

安装依赖后也可双击 **启动应用.cmd**。保持终端运行，打开 [找导师](http://127.0.0.1:8000/discovery.html)，按Ctrl+C停止。仅监听本机；8000被占用时执行 `python scripts/serve.py --port 8001`，相应使用8001访问。

如需隔离环境，先执行 `python -m venv .venv`，再用 `.venv/Scripts/python.exe -m pip install -r requirements.txt` 安装；启动脚本优先选择该环境。已有生成好的网页，不需要先采集、重建或下载Playwright浏览器。运行包不含解释器和预装依赖。

## 按申请流程使用

1. **找导师**：搜索姓名/研究方向，多选学校，查看研究、邮箱、来源日期及官网，候选加入对比。
2. **学校与要求**：选择院系、年度、学位、渠道和正式专业，核对条件、材料及时间，展开原文。
3. **保存项目**：明确保存结构目标，登记本机材料并关联项目，按阶段保存人工状态和文件版本。
4. **我的申请**：保存联系目标和草稿，导出EML在外部客户端发送，再记录实际已发、回复及下一步。
5. **提醒与备份**：为项目和导师设置多个提醒，分别备份工作台及筛选核验；材料原文件需另存。

## 私人数据与升级

私人项目、材料路径、草稿和历史通过本机API保存，不进入公开网页或运行包。首次明确保存才创建私人工作流；程序不自动发信、上传或报名。

工作台备份不带材料原文件、学生画像/SOP和独立信件，筛选核验备份独立。升级请解压到新目录，先导出备份、另存原材料，再恢复并核对路径；不要直接覆盖自己旧data目录。

## v1.3 保研机会与持续更新

新增入口 `opportunities.html`：按活动类型、毕业届别、学校和状态筛选，区分活动年份与入学年度，保留条件、材料阶段、截止时间和官方来源。v1.3整理10条：1条冬令营待复核、1条已核验科研实践（受理至2027年1月，具体截止日未公布）、1条即将开始的本科生科研实践、7条历史参考。当前没有可确认正在报名的条目。软件所29个方向、8个部门与15个公开邮箱支持直接搜索和联系。监测配置扩至36个官方栏目，不能当全量冬令营覆盖。

本机点击“加入我的申请”可明确保存活动快照、关联文件和可选个人提醒；不会代报名。政策来源过期时，可保存个人材料准备事实，仍标记待复核；来源变化/失败/缺失和目标、文件校验保留。

监测单次运行：`python scripts/monitor_opportunities.py`；常驻运行：`python scripts/monitor_opportunities.py --watch` 或双击 `启动信息监测.cmd`。默认每6小时，程序关闭/电脑休眠时不会更新。服务器使用 deploy 下的 systemd timer，可脱离本机持续运行。页面显示上次检查、下次应检和失败数；首次基线不标新发布，后续发现仍需核验，原文页面变化不等于招生条款变化。

公网服务 `scripts/serve_public.py` 提供公开资料与 HTTPS 通知订阅，不开放私人申请API。部署不携带私人记录或原材料。现有v1.0客户端不能保证读取含活动快照的v1.1备份；升级前保留旧备份。

公开站点：[HTTPS 保研机会](https://8.213.137.82:8443/opportunities.html)。浏览器通知需用户点击订阅并授权；支持按学校、活动类型和关键词订阅，可随时退订。本机私人提醒不会上传服务器。本机版通过 `data/opportunity_feed.json` 读取该服务的公开更新（最多缓存5分钟），不会上传私人工作流。同步失败明确降为本机快照；可将 enabled 设为 false 使用本机独立监测。服务器定时目标为北京时间02/08/14/20点，不代表官网发布到人工核验的实时保证。

维护者核验：`python scripts/review_opportunities.py sync` 生成/更新草稿与正文证据，`list` 查看待办；编辑草稿的 `item` 和原文摘录 `quotes` 后，以 `publish ID --sha256 HASH --reviewer NAME --note NOTE` 明确发布。发布会重新取回正文并核对来源、SHA及摘录，不通过就保留旧目录。默认队列在 `cache/opportunity_review.json`，成功证据24小时内复用；`sync --refresh` 强制取回。服务器每轮栏目监测后自动同步草稿，但不会自动确认申请资格或发布时间。

本机申请项目现在比较活动最新记录，提示截止、材料、条件等差异，保留原快照、个人进度和提醒；需要本人核对后调整。公开站明确使用“在本机准备申请”，转到本机时保留所选活动。来源失效或监测超时会降低信息状态，不继续宣称已确认报名开放。

## v1.4 届别、阶段与内容核验

[招生通知](https://8.213.137.82:8443/notices.html)默认展示当前周期和下一届准备，提供历史、待核验、渠道及独立年份筛选。2027入学推免属于历史；2027入学统考是当前备考与后续安排，不代表报名仍开放；2028届准备活动须有明确面向对象。普通招生通知不重复展示无关空年份，条件依据可以展开核对。按渠道筛选时可另看同年通用章程。

新增核验11校24条统考政策，累计30/111条本轮已复核，仍有81条待复核；政策来源160成功/23失败。服务器本轮再尝试120位导师，82成功、29失败、9需人工处理。通知36栏目真实检查成功，360条包含历史和未知，不能当作360个可报名机会。维护任务每6小时检查通知并重建页面。

PDF核验发布现需同时确认主页面与附件版本、逐字段原文及页码；附件变化阻止自动续检。同济2027推免PDF已按历史资料发布，目录共11条（3当前线索、8历史），没有新增已确认正在报名的项目。高能所官方正文仍因证书失效/别名404不能恢复核验，不用搜索缓存冒充当前可报名证据。
