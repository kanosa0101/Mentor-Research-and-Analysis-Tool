# 使用手册 · v1.2 本机版与公开信息站

本工具服务于CS学生寻找导师及整理研究生申请。信息来自已接入的学校、院系官网；资料齐全、导师资格和某年度招生名额是不同的事情。申请资格和实际提交仍以当年官方文件为准。

## 1. 启动与第一次使用

安装Python 3.12或更新版本（本次验证3.14），在程序目录执行 `python -m pip install -r requirements.txt`。已有生成好的网页，不需要首次重新采集或构建，也不需要下载Playwright浏览器。

Windows双击根目录的“启动应用.cmd”，保持终端运行，打开 [找导师](http://127.0.0.1:8000/discovery.html)。命令行也可执行 `python scripts/serve.py`。停止时按Ctrl+C。端口冲突时执行 `python scripts/serve.py --port 8001`，相应改用8001访问。程序只监听本机。

当前开发工作区另有18768预览服务，它不属于运行包的固定配置。复制运行包后默认使用8000。

## 2. 缩小导师范围

先输入姓名或研究关键词。多个研究词按“任一命中”查找，姓名与研究条件取交集。学校可以搜索、勾选、批选当前搜索结果；清除搜索不会清掉已选学校。修改条件后点击“查看候选”应用。

“更多条件”里可选择学位、渠道、相关院系及严格/偏好条件。院系方向是导航，不能直接判断跨专业资格；字段未知时不应当作不符合。默认优先展示信息较齐全的导师，同等完整度随机排列、会话内稳定；显式匹配条件优先。

导师卡片先看研究方向、简介、邮箱和来源时间，再打开官方资料。加入对比后到“更多工具→导师对比”并排查看，1位也可先保存候选。名单登记跨院系时不按同名自动合并。

## 3. 核对学校、院系和专业

在“学校与要求”选择学校、院系、入学年度、学位、申请渠道、普通/专项及正式专业。校级规则与院系、专业补充需一起看；不同专业、报考点或身份的条件不能互借。

查看资格、材料、考试、时间、学费、奖助、计划和咨询入口。展开原文与定位，核对官方链接、摘要核对日及来源成功检查日。回源失败、缺少院系文件或只有目录时保留缺口；来源近期成功不等于政策仍在报名。

招生通知是待核验候选。区分通知发布时间、入学年度和事项截止，不把上一年复试通知当本年度要求。已截止批次可用于回顾，不能作为当前开放证明。

## 4. 保存自己的申请目标

从政策页进入“创建申请目标”会预填范围，仍需填写项目名并明确保存。一个项目记录学校、院系、年度、学位、渠道、普通/专项、专业代码和名称。同一导师不同年度或不同项目分别推进。

在“准备清单”核对当前项目事项，可按阶段和人工登记状态筛选。未登记、需补正或来源/文件需复核归待处理；条件事项先展开核对，适用后再确认。筛选不保存记录，数量也不表示所有事项适用或要求已经齐全。

先在“材料”登记本机文件并关联项目，再为具体动作选择文件、填写状态和备注、保存本次准备记录。历史保存文件路径、大小、修改时间和内容指纹；文件变化后会提示复核。“已准备”“已登记提交”均是人工记录，不会向学校上传。

## 5. 联系导师、记录回复与下一步

导师卡片“准备联系”进入“我的申请与联系”，先选项目，再保存导师目标、选择理由和优先级。查看官网研究材料后填写邮件主题、正文、收件人及相关文件，明确自己的兴趣与经历，不根据未核实信息编造契合度。

保存草稿或导出EML，在外部邮件客户端检查收件人、正文和附件后发送。程序不会自动发信。实际发送后再点击确认已发送；之后可追加回复、约谈或补材料等沟通记录，旧记录不覆盖。

为下一步添加多个提醒，可分别归属项目或导师。保存官方日期不会自动生成提醒；按明确事项创建提醒时保留原文和来源，个人计划要作为个人计划登记。日期级事项不虚构具体时刻。

## 6. 换目标、文件变化与未保存输入

切换项目或修改目标后，旧目标记录不会直接当当前进度。来源变化、证据失效或文件修改时应重新核对。表单未保存时离开、切换或筛选会提示；取消后可继续编辑。

加载中的清单与真正无清单分别显示。读取失败可点击重新核对，不能据失败判断没有材料要求。

## 7. 备份和迁移

项目页“导出工作台备份”保存项目、目标、材料索引、草稿、沟通历史、提醒及准备记录。**不包含材料原文件**，也不包含学生画像、SOP和独立信件文件。找导师页的条件/核验备份独立保存；比较候选及部分视图偏好属于当前浏览器localStorage，不能当作已进入工作台备份。

恢复会替换对应私人数据文件，不是合并；替换前自动备份旧文件。先另行保存原材料及整个私人data文件夹，不要直接把新的运行包覆盖到自己正在使用的目录。

升级可解压到新目录，先启动空白版确认可用，再通过页面恢复相应备份、另行迁移原材料，并核对路径。旧工作流读取兼容不代表已经重写文件，首次明确写入时才按对应流程保存。

## 8. 当前边界

原有导师与正式政策资料沿用此前目录，本轮补充活动与监测，不代表旧资料全部刷新。39校、59配置单位中56个已有师资名单，共7173条；111条政策、310项材料动作仍不能代表所有院系、专业与身份要求已齐。2026-11-15开始轮转刷新旧来源；本批48位导师中42位成功，6位保留旧资料。大部分旧记录仍待处理，请查看每条的检查和人工核验时间。

学习形式、就业方式和报名批次还没有独立目标字段；遇到全/非全日制、定向、特殊批次等日期，须自行核对标签和原文。个人申请提醒依赖本地页面与服务。公开活动更新已支持 HTTPS 浏览器订阅；没有同步账户或官网代报名。真实邮件送达、招生资格和申请结果不在本次验收范围。

## 9. 保研机会与监测（v1.1）

“保研机会”默认展示当前线索，历史活动需切换查看；未核实的截止和条件不代表已经开放报名。活动年、毕业届别与研究生入学年份分开。展开可看条件、材料提交阶段、报名入口与核对出处。

本机版点击“加入我的申请”，核对项目名称和可选个人提醒后保存。项目中保留活动资料快照，可关联本机材料；后续官方更新不会覆盖旧快照，需回活动页核对。保存参考活动不代表报名成功。

独立监测每6小时运行一次，只在监测程序或服务器运行时生效。新发现先作线索，人工核验后才补齐截止、条件和材料。公开站点只供浏览，不接收私人文件或项目；私人操作仍需本机服务。

## 10. 活动变更与公开站衔接（v1.2）

公开站点点击“在本机准备申请”后，按页面提示启动自己的本机服务，再打开所选活动。使用默认8000端口时链接会保留活动；自定义端口需相应修改地址。无需在公开站上传简历。

已保存的活动项目会检查当前目录，显示条件、材料阶段、截止等变化。变更提示不覆盖保存快照、个人准备进度或提醒；请核对原文后自己调整安排。页面无法读取更新时会明确说明，历史快照仍可查看。

科研实践与正式招生分开。软件所当前科创计划的受理月份已知，具体截止日未公布；优先查看申请对象和分阶段材料，展开“研究方向与联系人”或搜索方向、部门、联系人，点击邮箱在自己的邮件客户端联系。每条保留官方附件与单元格出处；请向对应部门确认时间。

## 11. 浏览器更新通知（v1.3）

打开 https://8.213.137.82:8443/opportunities.html，在通知区选择学校、类型或关键词，再主动订阅并允许浏览器通知。可以发送一条连接测试通知，或随时退订；页面不会在打开时直接索取通知权限。HTTP 入口与本机版会引导前往 HTTPS 站点。

通知包括符合订阅条件的已核验发布、重要字段变化和明确截止前提醒；“新发现线索”需另行选择，它们尚未核验。后台推送依赖浏览器、操作系统及推送服务支持，关闭后台运行或系统禁止通知可能影响到达。站内更新记录可回看；来源检查时间与人工核验时间分别显示。

个人项目、材料、邮件草稿和个人提醒仍只保存在本机，不会随公开活动订阅上传。方向和联系人会随明确保存的活动快照保留；后续原文变化会提示核对，不自动改写自己的准备记录。

## 12. 按届别查招生通知（v1.4）

先选择查看范围、申请渠道和研究生入学年份。例如“2027入学＋全国统考”查看本轮备考、确认及后续安排；“2027入学＋推免＋历史参考”查看上一轮材料和要求。不要将旧要求直接当作2028年推免条件。

冬令营标题里的2027通常是活动举办年份，是否面向2028届须看明确对象。“更多年份条件”可单独筛选本科毕业届别和活动年；不能用公告发布日期代替这些年份。未能确认的条目在“待核验”中保留，不代表院校没有发布。

筛选统考或推免后，“查看同年通用政策”可查尚未拆分渠道的校章与专业目录。结果、名单、成绩是申请阶段，不直接等同于往届；当前周期中的后续通知仍可查看。已整理的资料可继续打开条件、材料与官方PDF页码依据。
