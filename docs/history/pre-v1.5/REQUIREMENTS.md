# v1.0 功能与范围基线

服务于CS学生寻找导师与整理研究生申请，以用户明确操作为边界，不代替学校审核。

| 用户需要 | 已提供 | 边界 |
| --- | --- | --- |
| 找研究兴趣相关导师 | 姓名/研究搜索、学校多选、院系导航、官网、候选对比 | 5649条来源超过30天；未知不等于不符合 |
| 判断条件和报名时间 | 学校/院系/专业分层、年度/学位/渠道、原文/来源状态 | 资格人工核对，批次及学习/就业形式未独立建模 |
| 准备材料 | 69政策310动作、条件、阶段/状态筛选、文件关联/版本 | 不代表要求全齐，无自动合规认证 |
| 联系导师 | 项目内目标、理由、草稿、EML、明确已发确认 | 不自动发信，未验证送达 |
| 推进申请 | 追加沟通历史、项目/导师多提醒、待办及旧目标隔离 | 阶段/提交人工记录，无后台推送 |
| 保留与迁移 | 工作台和核验分别备份恢复、原指纹历史 | 不含材料原件，候选localStorage独立 |

## 数据基线

39校59配置单位，56单位有7173记录，天津ai/cyber/software仅政策。111政策183来源/检查96入口；最近180成功3失败。42政策无材料动作，其中部分只含目录/科目，不能认定无材料要求。18通知栏目182候选，0人工核验。

已有字段：5660公开邮箱、2585明确方向、4940简介、3969导师资格。这是登记完整度，不证明准确、仍有效或可送达。来源日期与分层缺口见发布验收。

## 不变量

1. 未知、获取失败、内容变化、过期和范围未明分别保留，不凑默认值。
2. 专业、专项、身份、报考点及批次要求不借其他目标，通用与补充层一起核对。
3. 摘要与原文/日期/出处关联，回源不自动改人工结论。
4. 未保存输入能取消离开，旧目标不当当前进度，文件变化需复核。
5. GET兼容不主动迁移，显式保存/恢复才写，恢复前备份。
6. 私人资料不进公开载荷、运行包或Git，可写测试只用临时private。

## 不纳入完成声明

全库刷新、所有院系/专业/身份覆盖、全部细分日期自动判断、实时名额、资格认证、真实发信送达、官网自动报名/上传、后台推送、跨设备同步、真实AI写信/论文画像、其他系统和真实手机验证。用户要求暂停其他工作，本版不继续这些扩展。
