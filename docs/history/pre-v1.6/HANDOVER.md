## 学生资料与升级

浏览器关注目标/收藏/待办位于每个 origin 的 localStorage，导出浏览器 JSON 独立备份。导入预览后只合并新增项；不同设备、协议、域名、端口不会自动共享。它们不是本机正式项目。

本机私人文件包括 `data/workflow.yaml`、`data/discovery.yaml`、旧 `outreach.yaml`、学生画像、SOP、`letters` 和私人备份；材料原件通常在用户自行选择的路径。运行包、公开 ZIP 和服务静态根不得携带这些资料。

程序升级采用新目录：旧版分别导出工作台、筛选核验、浏览器备份，另存原材料与旧私人文件；新版本启动后恢复并核对路径。工作台恢复替换对应文件且先备份，不是合并；不要将旧 `data` 整目录覆盖新版本。保留旧程序和与其兼容的旧备份，直到升级核对完成。

工作流读取兼容不自动重写，明确保存时才沿既有迁移流程落盘。活动 `opportunity` 快照随正式项目保存，公开目录变化不会改个人快照、沟通历史或提醒。旧客户端能否读取新版备份必须实际检查，不能默认兼容。

## 公共资料版本维护

`crawler/public_snapshot.py` 负责构建公开归档；`crawler/public_update.py` 负责本机明确触发的下载和更新，不是命令行升级脚本。学生从申请导航底部“检查新版资料→更新公共资料”操作。

归档校验 schema、版本 ID、客户端版本、归档/逐文件 SHA-256、必要文件和路径白名单。白名单包含导师、学校、政策/入口/检查、通知、机会、覆盖和公开采集配置，不包含私人文件、代码或密钥。

客户端使用本机代码与模板在暂存目录构建，再替换明确的公开路径。下载/校验/构建失败不替换；文件替换异常按已执行路径回滚。旧公开文件保留于 `cache/public_updates/backup-<id前16位>/`，当前安装记录为 `cache/public-data-installed.json`。应用版本不同应先升级运行包，不能强行忽略版本校验。

人工回滚前停止服务及维护任务、另存当前目录，再按本次备份中实际路径恢复。不要合并覆盖私人目录；确认公开文件和页面版本一致后再启动，并核对安装记录。保留错误提示及备份，不为重试而删除备份。当前没有一键人工回滚界面；不能确认恢复范围时使用完整保留的旧运行目录。

## 候选核验与发布

```powershell
python scripts/monitor_opportunities.py
python scripts/review_opportunities.py sync
python scripts/serve_review.py
```

默认队列 `cache/opportunity_review.json`，证据在同目录的 `opportunity_evidence`。`sync --refresh` 强制回源；普通同步对新、失败或超时证据重新取回，保留人工字段。

维护台按当前轮次线索、截止、失败和等待时间处理。阅读原文、PDF 页码和版本差异，明确勾选采纳；随后核对完整项目和字段证据，保存草稿。发布填写核验人、说明并确认，重新抓取通过后才写公开活动目录。发布不自动部署。

兼容 CLI：`python scripts/review_opportunities.py publish ID --sha256 HTML_SHA --reviewer NAME --note NOTE`；PDF 每个文件额外提供一次 `--pdf-sha256 PDF_SHA`，草稿必须保留对应原文与页码。HTML SHA 与 PDF SHA 不可互代。扫描件、失效来源、错页和版本变化不能放行；`renew` 仅续检原已核验且未变化的记录，不批准新条件。

本机维护台仅白名单静态资源及 `/api/review`，写操作要求同源、CSRF 和队列锁内的 `expected_revision`。不能通过修改受管理字段伪造来源状态。源 HTML 按文本展示，不执行其脚本。

## 自动维护与告警

机会监测由 `deploy` 下的独立任务每六小时运行；公开维护每小时运行，通知未超过六小时则跳过重复抓取。实际运行情况查看对应记录。`maintain_public.py` 分阶段运行政策、导师、通知、续检、页面构建与公共归档；一个阶段异常不阻止独立阶段。失败写入 `cache/public-maintenance.json` 和 `cache/maintenance-alerts.json`，构建失败不发布新的公共资料版本。

当前申请单位在导师轮转中最多占本批一半，至少一半留给全库顺序轮转。不要将单批成功数解释为全库已刷新，也不要把源检查成功当人工摘要核验完成。

公共通知订阅、私人提醒和浏览器待办分开。首次来源基线不是新发布，候选不自动变开放报名；原文变化与招生条件变化需有证据区分。订阅密钥、订阅端点和私有服务状态不能进入发行包或公开日志。
