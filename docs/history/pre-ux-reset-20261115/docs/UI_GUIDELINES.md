# 页面与交互规范

本规范服务于三个动作：找到适合自己的导师或项目、弄清申请要求、推进准备与联系。页面按任务组织，不按数据表或维护流程堆叠内容。

## 信息层级

| 层级 | 内容 | 呈现方式 |
| --- | --- | --- |
| 直接看到 | 页面目的、当前学校/院系/筛选范围；能用于选择的研究方向、联系方式、申请对象、关键材料与官方截止；当前状态与下一步 | 简短标题、摘要与一个主要操作 |
| 主动了解 | 完整要求、不同专业与批次限制、报名步骤、完整导师介绍 | 明确命名的展开区或详情页，保留返回筛选上下文 |
| 核对依据 | 原文摘录、来源链接、核验时间、覆盖说明、抓取记录、旧版本与历史 | 靠近相关内容的证据详情；不挤占列表首屏 |

未知条件不能隐藏成“已符合”。摘要不能省掉影响申请决定的限制；不足以安全概括时标为待核对，并提供完整原文。高级筛选收起后仍显示已选范围。网址和锚点指向折叠内容时自动展开对应区域。

## 字体、颜色与空间

视觉变量集中在 `site/ui.css`，所有页面使用系统无衬线字体，不加载网络字体。

| 用途 | 规范 |
| --- | --- |
| 页面标题 | 28px，手机24px，700字重 |
| 区域标题 | 20px，650字重 |
| 卡片标题 | 17px，600或650字重 |
| 正文 / 控件 / 辅助文字 | 15px / 14px / 13px |
| 正文行高 | 1.65–1.7 |
| 内容最大宽度 | 1240px；两侧24px，手机16px |
| 卡片 | 白底、细边框、10px圆角；内距20px，手机16px |
| 控件 | 桌面至少40px高、手机44px；勾选框17px |
| 主色 | 深青绿；中性灰为辅助，黄/红只用于需要关注的状态 |

局部模板负责布局，共享样式负责字体、控件、颜色与基础间距。`_ui_head.html.j2` 放在页面自有样式后；找导师的首屏内联样式使用同一个文件。禁止新增页面级字号/颜色体系覆盖这些变量。

## 布局与操作

- 筛选按用户语言命名。姓名、研究方向、学校是常用项；申请核验与匹配规则放在高级区，不要求普通浏览者先理解内部规则。
- 卡片按内容自然高度，网格顶部对齐；不为稀疏资料设置固定高度。研究方向和联系信息紧靠姓名，证据按需展开。
- 每块区域只有一个明确的主要操作，次级操作使用中性按钮或文字链接。保存、发布与发送不得仅因展开或切换筛选发生。
- 表格溢出在表格容器内滚动，页面本身不得横向溢出。手机保留导航、筛选和操作，不能靠缩成小字塞进屏幕。
- 使用原生按钮、标签、details/summary与表单；所有关键操作可用键盘完成，焦点轮廓可见。刷新保留未保存输入，错误在对应区域说明。

## 验收

在1440px与390px检查主要页面，并补查窄屏和中间宽度。验证默认信息量、展开后完整性、筛选与返回恢复、比较/准备联系、材料与原文跳转，以及字号、焦点和横向溢出。找导师继续只取首批20位，不因视觉更新重新加载全量索引。私人流程只使用隔离数据验收。
