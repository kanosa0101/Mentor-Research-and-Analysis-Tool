# 导师库 · 申请助手

**v1.8.0 · 2026-11-15**。面向 CS 学生，把申请路径、导师、招生要求、保研活动和个人准备连接起来。本版增加官方证据与 AI 交叉核验、受限自动发布、来源候选发现和维护者审核提醒。保留导师首次 20 位按需加载，以及明确截止、持续招募和月份窗口的区分。旧版验收作为历史保留。

## 从申请导航开始

[公开申请导航](https://8.213.137.82:8443/start.html)无需安装，可浏览公开资料并在当前浏览器保存关注目标、收藏和待办。公开站根地址跳转到申请导航。

- **2027 年入学统考**：核对专业、考试与后续安排。当前周期不代表网上报名仍开放。
- **2028 届毕业保研准备**：按兴趣找导师，关注明确面向该届的冬令营、科研实践与后续招生安排。活动举办年份不等于毕业届别或入学年份。

浏览器收藏不等于正式申请项目，计划日期不等于官方截止，也不会触发后台个人提醒。准备材料、保存联系草稿和沟通历史请使用本机版。

## 启动本机版

从[本机版说明](https://8.213.137.82:8443/local.html)下载 v1.8.0 运行包并核对 SHA-256。安装 Python 3.12+，将运行包解压到独立目录，在该目录执行：

```powershell
python -m pip install -r requirements.txt
python scripts/serve.py
```

打开 [本机申请导航](http://127.0.0.1:8000/start.html)。安装依赖后也可双击 `启动应用.cmd`；保持终端运行，按 Ctrl+C 停止。端口占用时使用 `python scripts/serve.py --port 8001`。服务仅监听本机。

运行包已有网页，首次使用无需重新采集、构建或安装 Playwright 浏览器；Python 和依赖需自行安装。已有私人资料的用户先阅读下方升级说明，不要覆盖旧目录。

## 三类记录分别保存

| 内容 | 保存在哪里 | 如何备份 |
| --- | --- | --- |
| 关注目标、浏览器收藏、浏览器待办 | 当前浏览器、当前站点的 localStorage | 申请导航中“导出浏览器备份”；导入预览后仅合并新增条目 |
| 正式项目、材料索引、联系草稿、沟通历史、个人提醒 | 本机服务的私人工作流文件 | 项目页导出工作台备份；筛选核验另行导出 |
| 导师、政策、通知、机会与覆盖信息 | 公开资料目录与生成页面 | 通过“公共资料更新”维护；不覆盖前两类记录 |

HTTP/HTTPS、域名或端口不同，浏览器记录就属于不同站点；换设备或清除浏览器数据前请导出。工作台备份不包含材料原文件、学生画像、SOP 和独立信件，需另行保存。程序不会代报名、上传材料或自动发邮件。

## 将关注内容变成申请项目

在本机申请导航中，从关注目标或导师、通知、机会收藏选择“建立本机申请项目”，预览学校、关联目标和备注后确认。多校关注按单校建立项目；重复操作会复用已有项目并保留手工编辑。关联的有日期待办可转为个人提醒，无日期待办保留为备注，原浏览器条目继续保留。

公开站用户先导出浏览器备份，再到本机导入并建立项目。保研毕业届别保留在备注中，不猜测入学年份；统考目标明确的入学年才写入项目。

## 判断机会是否适合自己

机会页先看申请对象、研究方向、公开联系人、材料、报名方式和官方核验时间。长期科研实习、访问学生与正式研究生招生分别理解；招募公告在线不代表导师已经确认名额。

- **明确日期窗口**：只有官方开始和截止依据齐全且来源核验有效时才标为正在报名。
- **持续招募**：必须有“长期招收”“全年开放”等原文，单独展示；没有截止日期不能自动归入此类。
- **只明确截止月份**：不补成月末某日；进入截止月后提示确认具体日期，过月后按已结束处理。

先核对学校、年级、国籍、专业和费用限制。公告允许本科二年级及以上，可能包含当前大三，但不等于专门面向 2028 届或正式保研已开放。导师页面同列的博士、国际学生条件不能套给本科实习。

## 更新公开资料

在本机 `start.html` 底部点击“检查新版资料”，核对服务器资料时间与客户端版本后，点击“更新公共资料”。先保存其他页面输入，更新期间保持本机服务运行。

更新会验证 HTTPS 下载、归档及逐文件 SHA-256、schema、路径白名单和客户端版本；在暂存目录完成页面构建后才替换公开资料。下载、校验或构建失败不替换原资料，文件替换异常会尝试恢复该次备份。私人项目、材料路径、历史、活动快照和浏览器记录不在替换范围。公共资料更新不会升级程序代码，版本不一致须先换用对应运行包。

成功更新前的公开文件保留在 `cache/public_updates/backup-<资料版本前16位>/`。完整升级、故障处理和回滚步骤见 [使用手册](USER_GUIDE.md)。

## 当前覆盖与限制

v1.7 的 2026-11-15 基线登记 18 条机会：明确日期正在报名 1 条、月份窗口 1 条、持续招募 6 条、尚未开始 1 条、待复核 1 条、已结束 8 条。当前数量和变化请看[本版数据快照](docs/DATA_SNAPSHOT.json)及交付记录；基线数字不表示 18 条都能报名。监测配置共 61 个来源；实际请求成功率和部署状态见交付记录。导师目录登记 39 所学校、59 个配置院系、7173 条记录，其中 56 个院系有导师记录；登记范围不等于完整、最新覆盖。

覆盖页逐单位列出政策、材料、日期、导师和来源缺口；具体数量与本轮刷新结果以本版交付记录和当前页面为准。历史政策、已结束活动及结果公示可供参考，但不计为正在报名。官方来源失败时保留旧资料和失败状态，不用搜索摘要代替官方核验。

已接入来源的新公告进入核验队列；自动发现的新栏目先由维护者明确准入。少量结构明确、证据齐全的官方 HTML 可经规则及 AI 交叉核验自动发布，其余保留人工处理原因。确认报名条件仍需官方正文、PDF 或受支持的 DOCX 附件证据。附件保留独立版本及字段定位，链接或文件变化后降为待复核，不自动延用旧条件。监测页显示真实回源时间，调度运行不会把旧数据伪装为刚更新。

## 维护者入口

```powershell
python scripts/review_opportunities.py sync
python scripts/serve_review.py
```

在 [本机核验工作台](http://127.0.0.1:18769/review.html)查看队列、原文、建议、差异和 PDF 页码，明确采纳、编辑或核验发布。DOCX 附件和持续/月精度窗口由维护者登记结构化草稿证据，再通过同一发布门禁；当前没有专门的附件或窗口编辑器。发布会重新取证；受限自动模式的适用范围、人工阻断条件与排队规则见[自动核验说明](docs/AUTOMATIC_REVIEW.md)。核验服务固定监听本机，公网 `review.html`、`review.js` 返回 404，不提供审核写接口。
