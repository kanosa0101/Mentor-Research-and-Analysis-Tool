## 使用

```powershell
python scripts\serve.py
```

打开 `http://127.0.0.1:8000/`，进入导师库、套磁看板或招生通知。详情页填写下一步/日期/标签；看板导出跟进备份、筛选到期待办。跟进备份仅包含 outreach，不包含简历、学生画像、SOP 或信件文件。

刷新招生栏目后需重建站点：

```powershell
python scripts\monitor_notices.py --refresh
python scripts\build_site.py
```
