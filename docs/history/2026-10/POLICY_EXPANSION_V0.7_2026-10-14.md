## 验证与复查

追加前 `cache/policy_v7/verify_append.py` 在独占缓存完成真实网络检查、正文 fingerprint、24个引用/事件片段匹配、validator及dry diff。dry diff无删除行；旧9条policy/source/check逐项相等后才追加。

追加后运行：

```powershell
python -X utf8 cache/policy_v7/verify_final.py
python -X utf8 -m unittest tests.test_admissions -v
git diff --check -- data/admissions.yaml data/admissions_checks.json
```

结果：validator、原9对象不变、4新增2027上下文、5新增网络来源检查、6个被引用fingerprint（含东南旧正文hash）、24个引用/事件片段按各自明确来源检查通过；`tests.test_admissions` **14 tests passed**（原9 + 新增5）。新增来源导航测试先在旧校验器下复现合法label/source_ids拒绝以及字段引用规则缺失，再验证最小实现；覆盖旧格式兼容、字段/事件合法引用、label非空字符串、空/重复/未知/未登记/未reviewed引用、引用类型及label不改变hash。目标文件diff格式检查通过。四份PDF均实际下载并提取全文；已渲染检查所有引用涉及的页（华科1—5、7；武大两PDF全部3页；东南1—2），重点复核专业/专项表、日期、材料例外、权重公式和咨询岗位。
