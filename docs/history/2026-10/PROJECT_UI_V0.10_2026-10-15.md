# 申请项目目标与要求 UI v0.10

项目现可显式保存学校、院系、入学年度、学位、渠道、普通 / 专项类别和正式专业代码与名称。未知允许留空；旧学校、院系、申请类型文本保留在“旧说明”，不推断成结构化目标。已有项目列表先于编辑表单，自然展开，无内部高度截断。

“目标与要求”连接现有 AdmissionsRules 清单：目标完整才显示相同范围的政策；材料要求保留摘要、原文、定位、来源和来源检查状态。专业未指定、专项对学校通用规则适用未知时明确标注，不能据此导入官方事件。材料仅统计直接关联项目的已登记文件与缺失数，不自动判断要求满足或资格。

日期区分报名 / 材料截止、考试安排、资格相关时间、个人计划。官方事件由用户逐条加入，保留原事件类型、时刻、原文及全部来源引用；来源链接指实际事件来源（含 PDF），日期状态按北京时间判断。历史政策变化或移除时快照保留并提示重新核对，来源 URL 变化时另显示登记时来源。手动计划可附未经核验的参考来源。

目标改变时，保存前明确确认清理官方快照，手动计划保留。提醒由用户逐条设置，不自动批量生成；项目级同名同日提醒去重。精确时间按北京时间日历日期创建提醒，原始时刻、时区和来源保存在备注。联系人工作台优先传播已保存项目目标，跨院系导师显示适用性待核对，未结构化旧项目继续保留旧版保护。私人项目 ID 仅在申请工作台与联系人之间传递，用于默认项目选择与返回筛选；公开政策和导师发现链接不含私人项目 ID。无效项目 ID 不推断成其他项目。

验证使用 `python scripts/project_v10_ui_check.py`，只运行临时站点和临时私人索引。覆盖旧文本不迁移、结构目标编辑往返、手动计划、提醒去重、精确官方事件、原来源链接、历史政策消失、目录单位消失后原 ID 保留、目标变化取消与确认清理、跨院系联系人范围、时区跨日与 date-only 今天未过期。最初测试因缺少目标学校控件失败；跨时区测试先因缺少 reminderDay 失败，再完成实现。

本轮未运行抓取、公开 AI 生成、真实私人数据迁移或完整站点构建。政策样本仍不是完整招生数据库，历史快照与材料存在性均不能证明申请资格、完成度或报名开放。
