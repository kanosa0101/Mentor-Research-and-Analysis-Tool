# 在线服务调整：账号与云端申请

决策日期：2026-11-15。用户明确取消本机版本，并选择“账号登录、云端保存、支持跨设备使用”。本文件替代 v1.10 中公开站转本机、下载运行包和客户端升级的产品约定；旧交付报告仍作为历史证据保留。

## 产品边界

学生只打开 HTTPS 网站。无需安装 Python、下载程序、启动服务、填写电脑目录或手动更新公共资料。未登录可以找导师、看院校活动和学校要求；个人保存行为使用账号。收藏、关注目标、个人待办、正式申请、材料和沟通记录不能因换浏览器而消失。

“保存申请”表示保存自己的准备记录，不表示向学校报名；“保存草稿”不表示已经发送邮件。公共活动通知与个人计划提醒继续分别表达。

## 系统边界

| 区域 | 保存内容 | 访问边界 |
| --- | --- | --- |
| 公共资料 | 导师、学校要求、活动、来源、公开更新 | 匿名可读，现有维护发布流程更新 |
| 账号 | 用户名、密码校验信息、会话 | 服务端校验，客户端不保存密码或会话令牌到 localStorage |
| 云端个人记录 | 收藏、目标、待办、申请、材料、邮件草稿、沟通记录 | 服务端从登录会话确定账号，逐账号隔离；不接受客户端指定其他账号目录 |
| 维护管理 | 原文、审核、采集与AI配置 | 保持原维护入口，不因开放用户账号而开放管理接口 |

保留现有申请数据结构，按账号划分存储。共享公共资料与账号私人目录分开；不能通过切换全局 ROOT 或把所有请求指向旧 data/workflow.yaml 来实现多用户。公共资料更新和页面构建不读取或打包账号目录。

旧服务器私人文件不自动分配给第一个注册用户。旧浏览器记录须由本人明确确认导入，不能在登录时悄悄上传，退出后不能留着上个账号内容作为下个账号的工作副本。

## 四阶段实施与验收

1. **账号和隔离**：注册、登录、退出、过期会话；未登录拒绝私人API；A账号不能读写B账号的记录与材料；跨站写入与不安全返回地址拒绝。
2. **申请与材料上云**：复用既有项目、联系、材料和提醒流程，上传文件代替电脑目录扫描；两个独立浏览器登录同账号后能读取相同记录及材料；重复和并发操作不能破坏关联。
3. **统一在线体验**：取消下载、localhost跳转、启动说明、客户端更新与旧本机筛选导出入口；登录后返回原导师/活动/项目；收藏与关注目标明确显示保存成功或失败，冲突不能假装成功。
4. **验收与部署**：账号隔离、上传下载、主流程和多尺寸浏览器检查；备份部署并保护原有数据；公网新建专用测试账号复验，记录实际结果，不再生成或交付用户运行包。

## 验收用况

- O-01：匿名查看导师→准备联系→注册/登录→回到原导师。
- O-02：浏览器A创建申请、关联导师、保存沟通和提醒→浏览器B同账号读取。
- O-03：上传材料并关联项目→第二设备下载，字节一致；另一账号无法下载或关联。
- O-04：收藏导师、保存关注目标→另一设备读取；未保存/失败不能显示云端已保存。
- O-05：退出→私人API拒绝→换账号看不到前账号记录。
- O-06：老 local.html 和运行包地址不再引导安装；维护接口与服务器旧私人数据仍不可公开访问。
- O-07：在真实HTTPS上打开“我的申请”和“项目与材料”，页面完成会话识别及工作流初始化；不能只用HTTP开发服务证明线上可用。
- O-08：通过页面表单创建项目、关联导师、上传文件、保存草稿、登记实际发送及回复；刷新后核对，第二浏览器读取。网络失败、会话过期、材料超限或缺少必要关联时保留可恢复状态，不显示虚假成功。

## 实现约束与待记录限制

会话使用 HTTPS、HttpOnly、Secure、SameSite cookie；私人写操作核验同源及CSRF令牌。密码采用带独立盐的慢哈希，登录有频率限制。材料使用服务端生成ID、文件名与大小约束，存于静态站目录之外；下载仍检查账号，不直接公布文件路径。设计参考 [OWASP会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)和[文件上传指南](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)，具体覆盖以实现和测试为准。

不增加第三方登录、自动发信或学生材料AI分析。当前没有邮箱验证、邮件找回、自助注销或异地自动容灾。单文件20MB、每账号200MB；记录备份不含材料原件。账号收藏采用版本冲突检查，申请工作流无逐字段合并，同字段以后一次成功保存为准。备份、恢复和实际验证边界见[使用手册](../USER_GUIDE.md)、[维护交接](../HANDOVER.md)及[本轮交付记录](../deploy/DELIVERY_V1.11.3_2026-11-16.md)。
