# 内容归类、来源与展示规则

状态：2026-11-15产品整改要求，尚未执行迁移或接入发布门禁。适用于已有内容整理及既有更新任务，不要求扩大采集或增加新功能。

## 一、先判断“是什么”，再判断“能否报名”

| 内容 | 进入哪里 | 判断依据 | 不允许的替代判断 |
| --- | --- | --- | --- |
| 学校、学院、正式研究所统一组织的冬夏令营、暑期研修等 | 活动页；历史营单独查 | 具名主办方、活动对象与统一安排的官方公告 | 标题含“科研”、URL属于学校，即当学校活动 |
| 院校/院所统一科研项目，例如软件所科创计划 | 活动页，明确标“院所科研项目” | 院所统一发起、申请/选拔/管理流程；不是某导师个人岗位 | 把科研项目称为保研录取，或计入冬令营数量 |
| 导师/课题组/实验室个人招实习生、访问学生 | 导师招募标签与详情 | 负责人身份、招募对象、原文和联系方式 | 官方实验室网站托管就视为全院所组织；职位联系人就视为导师 |
| 正式推免预报名、统考报名、复试/考核安排 | 招生通知；经结构化核验后关联学校要求 | 招生轮次、渠道、专业/身份与具体阶段 | 为丰富活动列表，把所有正式招生公告当夏冬令营 |
| 学院内部实习管理/导师岗位征集通知 | 先作为待整理线索；证据齐全再定去向 | 是否有面向学生的项目、岗位、对象与申请流程 | 导师征集期当学生报名期；“全体本科生”推断面向全国 |
| 搜索摘要、主办层级未知、缺正文、重复记录 | 核验队列/次级待核验线索 | 保留已有来源及缺口 | 放入默认活动结果或计为开放报名 |

分类看实际组织者和流程，不能只看机构域名、栏目名或活动标题。不同对象可以在同一公告内出现，必须逐事项区分。只向本校学生开放的真实活动可以保留，但必须明示本校限制；未知范围不自动放宽。

## 三、用户必须能看懂的来源

| 位置 | 直接展示 | 进入详情查看 |
| --- | --- | --- |
| 活动卡 | 主办单位、活动类型、对象/届别是否明确、报名状态、关键时间、具名官方公告入口、最近核验状态 | 完整对象限制、材料与提交阶段、费用、报名步骤、附件及对应原句 |
| 导师卡 | 学校/院系、原始职称、明确博/硕导资格、方向摘要、公开邮箱、有效招募标签；简短资料来源与日期 | 字段各自出处、完整方向/简介、招募对象与时效、联系人角色 |
| 学校要求 | 当前目标、关键准入限制、材料和时间、摘要核验状态 | 学校/院系/专业完整适用条款、官方原文及附件 |

来源路径应能从“发现入口→公告正文→附件或报名入口→字段原句与定位”追溯。没有证明父子链接关系时只记录“候选栏目”，不能因为同域名就宣称公告来自该栏目。主办单位与发布网站/转载单位分别记录。

- 公告、附件、申请表、报名系统分别命名；相同URL的重复申请表入口合并显示，保留原始证据。
- 官方联系人和导师个人联系人标明角色；不能把研究生部、学院咨询或团队助理邮箱写成导师本人邮箱。
- 标题年份、毕业届别、研究生入学年分别表达。缺届别时展示官方年级/身份原句，不补“28届专属”。
- 公告发布时间、最后成功获取时间、内容核验时间分别保存。主列表展示最有用的核验状态，细节里可查全部日期；页面构建时间不表示信息新鲜。
- 原始SHA、模型名、解析器状态属于维护证据，不作为学生首屏内容。不能因为隐藏技术字段而隐藏来源失效或关键适用限制。

## 四、导师标签的证据边界

“博导/硕导”来自导师资格字段；职称、博士学历和招实习生都不能补成导师资格。“实习/访问学生招募”是独立招募事实，不写进supervisor，也不借用私人“招生机会已核对”结论。

最少保留：稳定招募记录ID、明确导师关联及依据、实际组织层级、招募类型/对象、研究方向、联系邮箱与角色、原文URL/引文、原文日期/核验日期、截止或窗口精度、当前证据状态。优先复用既有事实与provenance，具体存储方案在实施时选择最小改动。

标签措辞与证据一致：有有效原文的长期招募可标“长期科研实习招募”；对象仅称访问学生就标“访问学生招募”。时间不明/旧文应标“有招募记录·需核实”；来源失效或已结束不能继续宣称“正在招”。不推断实时剩余岗位、回复意愿或未来保研名额。

未关联招募保留在整理台账；旧活动ID、收藏和已存项目快照不能直接删除。旧链接应解释其归类变化并指向可靠的新去向，不重写私人历史。

## 五、分发与自动化必须使用同一范围

整改顺序：明确分类及证据→在候选/发布环节执行归类门禁→演练旧数据归位→统一API、页面、更新摘要、订阅和资料包→再开放迁移。不能只在前端隐藏6张卡。

1. 新发现的个人招募进入导师招募处理路径；组织层级未知进入人工核验，AI不能仅凭学校域名决定准入。
2. 既有证据门禁继续生效，新增归类门禁不能绕开原文、附件、人工编辑和并发保护。
3. 活动订阅不再接收个人导师岗位。旧推送/历史更新保留历史语境，分类搬迁本身不制造“新报名活动”批量通知。
4. 旧收藏、项目里的机会快照不随公共分类重写；页面读取到已迁移ID时提供清晰去向。
5. 来源发现继续监测有价值的个人官方页，但“被监测”不等于“被活动页收录”。不因缩小展示范围删除证据和维护记录。
