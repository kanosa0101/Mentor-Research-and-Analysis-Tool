## 维护者核验发布

```sh
python scripts/review_opportunities.py sync
python scripts/review_opportunities.py list
# 编辑 cache/opportunity_review.json 中对应草稿的 item 和 quotes
python scripts/review_opportunities.py publish ID --sha256 HASH --reviewer NAME --note NOTE
```

`sync --refresh` 可强制重新取证。`publish` 检查配置来源、机构域名、原文 SHA、摘录匹配与活动字段，原子更新单条目录并保留核验审计。正文变化、获取失败或字段不合规则拒绝发布，保留原目录。软件所科创计划已用真实官方正文走通该流程，证据见 `cache/review_v12_pilot/validation.json`。

这些检查保证证据与本次核验对应，不能自动证明维护者对资格条件的理解正确。自动草稿不猜年级对应届别，不猜截止日期，不自动授予已核验状态。服务器服务用户只可写缓存目录；人工发布由维护者执行。CLI 更新的是目录，静态页面与外部部署仍需维护步骤。

## 仍未解决及下一步

1. 当前可行动机会覆盖仍少，原有导师与 111 条政策未整体刷新。继续以官方栏目覆盖清单和当前申请机会核验为主，不以历史条目数量代替覆盖质量。
2. 新公告发现已自动化，关键条件提取与审核发布仍需维护者参与；目前没有自动审核时限或后台消息推送保证。下一步应减少人工转录，并把原文摘录和关键字段逐项对应。
3. 研究方向附表已取证，下一步把方向、部门联系人和项目申请入口结构化展示，减少学生下载附件查找的步骤。
4. 项目变更目前在打开本机工作台时检查，提醒不自动改期，也没有关闭应用后的通知。长材料列表的变更展示可进一步简化为新增/移除项。
5. 仍为 IP/HTTP 公开浏览与本机私人工作台，没有域名 HTTPS、远程账户或跨设备同步。本轮未扩展这些部署能力。
