## 持续运行与维护

| 任务 | 频率 | 边界 |
| --- | --- | --- |
| mentor-monitor.timer | 每 6 小时 | 36 栏目发现与来源检查，之后自动取证生成草稿 |
| mentor-maintenance.timer | 每小时第 20 分 | 每批最多 20 政策来源、40 导师；24 小时内跳过重复尝试；续检已核验且未变的活动；重建公开页面 |
| mentor-updates.timer | 每小时 | 事件去重、按订阅过滤、重试与失效订阅清理 |
| mentor-certificate.timer | 每日两次 | 检查续期，成功后更新证书并重载 HTTPS 服务 |

40 位导师/小时对应全库约 8 天的理想轮转时间，实际取决于失败与人工处理，不是刷新完成承诺。发现到通知也不是实时保证；新条件仍须证据核验。

维护命令：

```sh
python scripts/review_opportunities.py sync
python scripts/review_opportunities.py list
python scripts/review_opportunities.py accept ID --fields eligibility materials
python scripts/review_opportunities.py publish ID --sha256 HASH --reviewer NAME --note NOTE
python scripts/review_opportunities.py renew
python scripts/refresh_legacy.py --kind policies --limit 20 --workers 4 --timeout 12
python scripts/refresh_legacy.py --kind professors --limit 40 --workers 4 --timeout 12
```

`accept` 只采纳建议到草稿；`publish` 重新取回原文核对 SHA 和摘录；`renew` 仅续检已核验且正文、字段和摘录未变的 HTML 记录，保留人工核验日期。标题、正文与链接变化会进入复核，导航/脚本等噪声不单独构成条款变化。

服务器根目录 `/opt/mentor-assistant`。推送凭据及订阅仅在 `var/push`，不进入公开文件或运行包；TLS 私钥在 `var/tls`。短期 IP 证书当前有效至 2026-11-21，自动续期 dry-run 已通过。不要覆盖或重建 VAPID 密钥，否则旧订阅失效。原 443 的 xray 与其他服务保留，未挪用端口。

公开站仅接收通知订阅，不接收私人工作台或材料。HTTPS 写接口核对 Origin；退订和测试要求订阅自己的凭据。服务器不部署本机 `data/opportunity_feed.json`，避免读取自身；本机通过公共 API 获取更新。
