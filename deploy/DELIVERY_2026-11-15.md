# v1.1 部署与验收记录

验收日期：2026-11-15（北京时间）。

## 已交付

- 公开站点：http://8.213.137.82/opportunities.html 。提供保研活动、导师与招生资料浏览。
- 部署目录：`/opt/mentor-assistant`；独立非登录用户 `mentor-assistant`。
- `mentor-public.service` 与 `mentor-monitor.timer` 已启用并运行。公开服务监听 80；没有调整既有 xray / x-ui 的配置或端口。
- 官方栏目监测按北京时间每日 02:00、08:00、14:00、20:00 执行；开机补检，错过的计划由 systemd 补触发。网页的“下次应检”是上轮检查加 6 小时的健康期限，实际日历任务可能更早执行。
- 本机通过 `data/opportunity_feed.json` 读取公开信息流，缓存 5 分钟；服务器不可用时保留资料并提示无法确认最新状态。服务器没有部署该客户端配置，避免递归请求自身。
- 活动可在本机保存为申请项目，关联条件、材料阶段、日期与来源快照，并设置个人提醒、关联材料及备份恢复。
- 手机筛选折叠、学校选择摘要、资料质量清理，以及待核验政策下个人材料准备进度的保存已完成。

## 内容和时效边界

- 23 个官方栏目首轮 22 个成功、1 个失败；失败为北航网络空间安全相关旧入口返回 404。
- 首次收录 29 条线索属于基线，不代表当天新发布。后续发现才标记为新线索，仍需核验。
- 结构化活动 8 条：1 条当前待复核、7 条历史参考、0 条已确认正在报名。
- 高能所 2027 冬令营仅取得官方搜索索引线索，原文获取存在异常；保持待复核，不据此宣称报名开放。
- 页面 SHA 变化仅触发复核。已观察到访问计数变化产生的差异，不能当成招生条件变更。
- 自动化负责发现、取回、去重、变更检测和来源健康记录。申请资格、材料阶段、正式截止时间与报名状态仍需证据核验后才能更新为确认信息。
- 现有 7,173 条导师与 111 条政策未在本轮整体刷新；公开上线不等于旧资料已更新。监测覆盖也不等于覆盖所有学校院系。
- 尚无对外消息推送、远程账户或跨设备私人项目同步。公开站采用 HTTP；不接收申请材料、私人记录或凭证。

- Python 全量回归：347 项通过，3 条依赖弃用警告。随后新增远程信息流检查，与公开服务检查合计 14 项通过；打包检查 5 项通过。未把这些重叠检查累加成新的全量数字。
- Node 活动日期/状态与导师数据质量、既有筛选/范围回归通过。
- 本机 1440 / 390 像素实际操作：活动筛选、保存项目、个人提醒、材料关联、备份恢复通过；临时数据隔离，真实私人文件未改变。
- 公网 1440 / 390 像素：活动列表、监测状态、公开模式提示、私人工作台跳转通过；无横向溢出、无脚本异常、无写入请求。
- 公网健康检查与公开 API 返回成功；私人 API 和私人文件路径返回 404。
- 服务器逐文件 SHA 校验：7,230 个文件，0 个不一致，未发现私人数据文件。
- 原导师、招生政策、政策检查、通知数据文件无本轮差异；真实目录中未新建 workflow.yaml、workflow.json、discovery.yaml。
- v1.0 历史运行包未覆盖。

证据位于工作区 `cache/deploy_20261115/`（文件清单、截图、浏览器验收），`cache/opportunities_v1_1_ui/results.json`（本机完整流程），以及服务器 `/opt/mentor-assistant/cache/deploy-verification.json`。缓存目录不属于版本控制交付内容。

## 运维

```sh
systemctl status mentor-public.service mentor-monitor.timer --no-pager
systemctl list-timers mentor-monitor.timer --no-pager
journalctl -u mentor-monitor.service -n 100 --no-pager
systemctl start mentor-monitor.service
```

监测退出码 1 表示本轮存在部分来源错误；服务允许该退出码完成，需结合 JSON 报告及页面成功/失败数量判断，不能只看 systemd 的 success。运行结果保存在 `cache/opportunities_live.json`。

安装 Python venv 依赖时，系统包维护触发既有 aegis 服务重启失败；追查日志发现 11 月 14 日已有相同失败，相关常驻安全进程仍在。本轮没有修改它的配置；诊断记录保存在 `cache/aegis_diagnosis_20261115/report.json`。

下一阶段优先修复失败入口、扩大官方栏目覆盖，并完成新线索到结构化活动的核验发布流程。域名与 HTTPS、消息订阅和远程私人账户属于后续部署能力，本版没有将其标为已完成。
