# 导师库 · 申请助手

**v1.5.0 · 2026-11-15**。面向 CS 学生，把申请路径、导师、招生要求、保研活动和个人准备连接起来。本版增加申请导航、浏览器收藏与待办、本机核验工作台及公共资料版本更新；旧版验收作为历史保留。

## 从申请导航开始

[公开申请导航](https://8.213.137.82:8443/start.html)无需安装，可浏览公开资料并在当前浏览器保存关注目标、收藏和待办。公开站根地址跳转到申请导航。

- **2027 年入学统考**：核对专业、考试与后续安排。当前周期不代表网上报名仍开放。
- **2028 届毕业保研准备**：按兴趣找导师，关注明确面向该届的冬令营、科研实践与后续招生安排。活动举办年份不等于毕业届别或入学年份。

浏览器收藏不等于正式申请项目，计划日期不等于官方截止，也不会触发后台个人提醒。准备材料、保存联系草稿和沟通历史请使用本机版。

## 启动本机版

安装 Python 3.12+，将运行包解压到独立目录，在该目录执行：

```powershell
python -m pip install -r requirements.txt
python scripts/serve.py
```

打开 [本机申请导航](http://127.0.0.1:8000/start.html)。安装依赖后也可双击 `启动应用.cmd`；保持终端运行，按 Ctrl+C 停止。端口占用时使用 `python scripts/serve.py --port 8001`。服务仅监听本机。

运行包已有网页，首次使用无需重新采集、构建或安装 Playwright 浏览器；Python 和依赖需自行安装。已有私人资料的用户先阅读下方升级说明，不要覆盖旧目录。

## 三类记录分别保存

| 内容 | 保存在哪里 | 如何备份 |
| --- | --- | --- |
| 关注目标、浏览器收藏、浏览器待办 | 当前浏览器、当前站点的 localStorage | 申请导航中“导出浏览器备份”；导入预览后仅合并新增条目 |
| 正式项目、材料索引、联系草稿、沟通历史、个人提醒 | 本机服务的私人工作流文件 | 项目页导出工作台备份；筛选核验另行导出 |
| 导师、政策、通知、机会与覆盖信息 | 公开资料目录与生成页面 | 通过“公共资料更新”维护；不覆盖前两类记录 |

HTTP/HTTPS、域名或端口不同，浏览器记录就属于不同站点；换设备或清除浏览器数据前请导出。工作台备份不包含材料原文件、学生画像、SOP 和独立信件，需另行保存。程序不会代报名、上传材料或自动发邮件。

## 更新公开资料

在本机 `start.html` 底部点击“检查新版资料”，核对服务器资料时间与客户端版本后，点击“更新公共资料”。先保存其他页面输入，更新期间保持本机服务运行。

更新会验证 HTTPS 下载、归档及逐文件 SHA-256、schema、路径白名单和客户端版本；在暂存目录完成页面构建后才替换公开资料。下载、校验或构建失败不替换原资料，文件替换异常会尝试恢复该次备份。私人项目、材料路径、历史、活动快照和浏览器记录不在替换范围。公共资料更新不会升级程序代码，版本不一致须先换用对应运行包。

成功更新前的公开文件保留在 `cache/public_updates/backup-<资料版本前16位>/`。完整升级、故障处理和回滚步骤见 [使用手册](USER_GUIDE.md)。

## 当前覆盖与限制

本轮已复核 **69/111 条政策**，其余 **42 条**历史或其他政策仍未在本轮复核；**183 个政策来源中 181 成功、2 失败**。来源成功与摘要已复核是两项指标，均不代表当前仍能报名。15 个单位的覆盖与缺口可在 `coverage.html` 查看。

活动目录仍有 **3 条当期线索，0 条确认正在报名**。高能所冬令营线索受官方证书失效、别名页面 404 影响，不能用搜索缓存恢复“已核验”。导师资料持续轮转，具体本轮处理数量与失败项见交付记录；不宣称全库已刷新或名额已确认。

## 维护者入口

```powershell
python scripts/review_opportunities.py sync
python scripts/serve_review.py
```

在 [本机核验工作台](http://127.0.0.1:18769/review.html)查看队列、原文、建议、差异和 PDF 页码，明确采纳、编辑或核验发布。发布会重新取证；新条件不会自动核准。核验服务固定监听本机，公网 `review.html`、`review.js` 返回 404，不提供审核写接口。
