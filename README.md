# 导师库 · 申请助手

**v1.0.0 本机版 · 2026-10-15**。面向CS学生，从找导师、核对招生政策，到整理申请项目、材料、联系历史和提醒。本次整合发布现有功能，停止新增采集与扩展；数据快照及缺口一并交付。

## 启动

需要Python 3.12+，本次验证Windows、Python 3.14。解压运行包到独立目录，在该目录执行：

```powershell
python -m pip install -r requirements.txt
python scripts\serve.py
```

安装依赖后也可双击 **启动应用.cmd**。保持终端运行，打开 [找导师](http://127.0.0.1:8000/discovery.html)，按Ctrl+C停止。仅监听本机；8000被占用时执行 `python scripts/serve.py --port 8001`，相应使用8001访问。

如需隔离环境，先执行 `python -m venv .venv`，再用 `.venv/Scripts/python.exe -m pip install -r requirements.txt` 安装；启动脚本优先选择该环境。已有生成好的网页，不需要先采集、重建或下载Playwright浏览器。运行包不含解释器和预装依赖。

## 按申请流程使用

1. **找导师**：搜索姓名/研究方向，多选学校，查看研究、邮箱、来源日期及官网，候选加入对比。
2. **学校与要求**：选择院系、年度、学位、渠道和正式专业，核对条件、材料及时间，展开原文。
3. **保存项目**：明确保存结构目标，登记本机材料并关联项目，按阶段保存人工状态和文件版本。
4. **我的申请**：保存联系目标和草稿，导出EML在外部客户端发送，再记录实际已发、回复及下一步。
5. **提醒与备份**：为项目和导师设置多个提醒，分别备份工作台及筛选核验；材料原文件需另存。

## 私人数据与升级

私人项目、材料路径、草稿和历史通过本机API保存，不进入公开网页或运行包。首次明确保存才创建私人工作流；程序不自动发信、上传或报名。

工作台备份不带材料原文件、学生画像/SOP和独立信件，筛选核验备份独立。升级请解压到新目录，先导出备份、另存原材料，再恢复并核对路径；不要直接覆盖自己旧data目录。
